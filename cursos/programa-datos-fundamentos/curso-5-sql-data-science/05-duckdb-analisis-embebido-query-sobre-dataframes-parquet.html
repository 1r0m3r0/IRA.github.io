🦆 Módulo 5: DuckDB — Análisis Embebido sobre DataFrames y Parquet

SQL que vuela: analiza datos donde están, sin moverlos

Módulo 5 de 12 (0%)
💡 Piénsalo así: DuckDB es como tener un mini-SQLite pero especializado en análisis de datos. Mientras PostgreSQL es un camión de carga (genial para transacciones), DuckDB es un auto de carreras para consultas analíticas. Puede hacer SELECT directamente sobre DataFrames de Pandas y archivos Parquet sin importarlos — como un chef que cocina directamente en la fuente sin ensuciar platos.

DuckDB Simulado: Query sobre DataFrame

-- DuckDB query sobre DataFrame de Pandas SELECT region, AVG(venta) as promedio FROM df_ventas GROUP BY region ORDER BY promedio DESC;
