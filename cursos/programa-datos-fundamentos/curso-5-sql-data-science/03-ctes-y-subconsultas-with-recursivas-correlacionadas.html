🔄 Módulo 3: CTEs y Subconsultas — WITH, Recursivas, Correlacionadas

Consultas dentro de consultas: el Matryoshka de SQL

Módulo 3 de 12 (0%)
💡 Piénsalo así: Las CTEs (Common Table Expressions) con WITH son como preparar los ingredientes antes de cocinar: "Con estos datos temporales (WITH), luego haz la consulta principal". Las subconsultas correlacionadas son como preguntarle a cada alumno si está por encima del promedio de su clase — la subconsulta se ejecuta para cada fila. Las CTEs recursivas son como un juego de "el que sigue": empiezas con un valor y vas generando el siguiente.

Constructor Visual de CTEs

WITH ventas_altas AS ( SELECT region, SUM(monto) as total FROM ventas GROUP BY region HAVING SUM(monto) > 100000 ) SELECT * FROM ventas_altas ORDER BY total DESC;

📊 Resultado: Regiones con ventas > $100,000

Norte: $124,500 · Este: $156,300 · Oeste: $112,800
