🏗️ Módulo 11: OLAP vs OLTP — Row vs Columnar, Parquet vs Arrow

Dos mundos, una base de datos: elige la herramienta correcta

Módulo 11 de 12 (0%)
💡 Piénsalo así: OLTP (Online Transaction Processing) es como la caja de un supermercado: muchas transacciones pequeñas, rápidas, cada una afecta pocas filas. OLAP (Online Analytical Processing) es como el inventario anual: pocas consultas, pero pesadas, que leen millones de filas. Row-based (filas) es como una lista de compras: toda la info de cada ítem junta. Columnar es como tener todos los precios juntos, todas las fechas juntas — ideal para analizar solo ciertas columnas.

Comparador OLTP vs OLAP

⚡

OLTP

  • Muchas transacciones pequeñas
  • INSERT/UPDATE/DELETE frecuentes
  • Row-oriented storage
  • PostgreSQL, MySQL
  • ACID compliance
📊

OLAP

  • Pocas consultas grandes
  • SELECT agregados pesados
  • Column-oriented storage
  • DuckDB, ClickHouse, Snowflake
  • Compresión alta, scans rápidos
