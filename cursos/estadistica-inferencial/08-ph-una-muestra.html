z-test, t-test, test para proporción y test para varianza (χ²)

z-test (σ conocida) t-test (σ desconocida) Proporción χ² varianza
Analogía: Decidir si rechazar H₀ es como un control de calidad en una fábrica. Si la pieza está fuera de tolerancia (el estadístico de prueba cae en la región de rechazo), se rechaza el lote. El nivel de significancia α es el porcentaje de piezas buenas que incorrectamente rechazamos. Y el p-valor nos dice qué tan extremo es el resultado: si es muy pequeño, es como encontrar una pieza terriblemente fuera de especificación.
