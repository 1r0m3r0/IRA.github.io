PostgreSQL y SQLite para historial de operaciones

SQL Análisis CSV
🗄️ Piénsalo así: Un trade journal es como el libro de bitácora de un barco. Cada operación queda registrada: fecha, activo, dirección, precio, resultado. Sin un journal, estás navegando sin mapa: no sabes qué funciona, qué no, ni cuánto has ganado realmente. SQL es tu bibliotecario personal que responde cualquier pregunta sobre tu historial.

🗃️ Esquema SQL: Tabla trades

CREATE TABLE trades ( id INTEGER PRIMARY KEY AUTOINCREMENT, fecha TEXT NOT NULL, activo TEXT NOT NULL, direccion TEXT CHECK(direccion IN ('COMPRA','VENTA')), cantidad REAL NOT NULL, precio_entrada REAL NOT NULL, precio_salida REAL, pnl REAL );
