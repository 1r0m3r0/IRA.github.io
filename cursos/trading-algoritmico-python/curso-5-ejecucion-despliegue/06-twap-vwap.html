TWAP, VWAP, Iceberg, Implementation Shortfall

10000 unidades Simulación Costos
📊 Piénsalo así: Quieres comprar 10,000 entradas para un concierto. Si las compras todas de una vez, el precio se dispara (impacto de mercado). TWAP es comprar 500 cada 10 minutos. VWAP es concentrar las compras donde hay más volumen. Iceberg es mostrar solo 100 a la vez para no asustar al mercado. Cada estrategia minimiza el impacto de forma diferente.
