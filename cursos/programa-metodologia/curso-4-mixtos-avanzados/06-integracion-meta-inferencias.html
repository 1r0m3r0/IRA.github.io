¿Qué es una meta-inferencia?

Un análisis estadístico avanzado
La conclusión que surge de integrar datos cuanti y cuali
Un tipo de entrevista
Una revisión de literatura

¿Para qué sirve un joint display?

Para decorar el informe
Para visualizar la integración de datos cuanti y cuali lado a lado
Para reemplazar el análisis estadístico
Para hacer entrevistas

¿Qué ocurre si los datos cuanti y cuali discrepan?

Se ignora la discrepancia
Se analiza como hallazgo y se ofrecen explicaciones
El estudio se descarta
Solo se reportan los datos que coinciden
