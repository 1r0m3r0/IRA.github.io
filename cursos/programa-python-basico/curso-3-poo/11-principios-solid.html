💡 Piénsalo así: SOLID son 5 reglas de diseño como las de un arquitecto: S = una habitación, una función (no hagas una habitación que sea cocina y baño). O = si quieres una habitación nueva, no remodeles toda la casa. L = una silla debe poder reemplazar a una silla. I = no obligues a tener lavavajillas si solo necesitas fregadero. D = no conectes la lámpara directamente al cable de luz, usa un enchufe.
