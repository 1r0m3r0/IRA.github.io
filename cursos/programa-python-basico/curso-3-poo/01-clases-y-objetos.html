💡 Piénsalo así: Una clase es como el molde de una galleta (la forma de estrella). El objeto es la galleta que horneas con ese molde. Puedes hacer muchas galletas (objetos) con el mismo molde (clase), y cada galleta puede tener diferentes decorados (atributos). class = el molde, instancia = la galleta, self = "esta galleta en particular".
