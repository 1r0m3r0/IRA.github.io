💡 Piénsalo así: Pandas puede leer casi cualquier formato de datos: CSV (texto separado por comas), Excel (hojas de cálculo), JSON (datos anidados), SQL (bases de datos), Parquet (formato columnar rápido). Es como tener un traductor universal que entiende todos los idiomas de datos. read_csv() → "lee este CSV", to_excel() → "escribe a Excel".
