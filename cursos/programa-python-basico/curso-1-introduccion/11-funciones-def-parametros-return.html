💡 Piénsalo así: Una función es como una receta de cocina. Tiene un nombre (def hacer_platillo), ingredientes (parámetros), instrucciones (cuerpo) y un resultado (return). Cada vez que quieres ese platillo, solo sigues la receta — no necesitas reescribirla. def = "define esta receta", return = "aquí está el resultado".
