¿Qué es Python?

Python es un lenguaje de programación de alto nivel, interpretado y multipropósito, creado por Guido van Rossum en 1991. Su filosofía se centra en la legibilidad del código y la productividad del desarrollador, permitiendo expresar conceptos complejos en menos líneas que otros lenguajes como C++ o Java.

A diferencia de muchos lenguajes, Python usa la indentación (espacios en blanco) para definir bloques de código, eliminando la necesidad de llaves o palabras clave. Esto obliga a escribir código limpio y bien estructurado desde el primer día.

Grandes empresas como Google, Netflix, Spotify y NASA confían en Python. Se usa en desarrollo web, ciencia de datos, inteligencia artificial, automatización, scripting y más.

Instalación paso a paso

Para instalar Python, visita python.org y descarga la última versión estable (3.12+). Durante la instalación en Windows, marca la casilla «Add Python to PATH» — este es el error más común que impide ejecutar Python desde la terminal.

En macOS puedes usar Homebrew: brew install python3. En Linux, la mayoría de distribuciones incluyen Python, pero puedes instalarlo con sudo apt install python3 (Debian/Ubuntu) o sudo dnf install python3 (Fedora).

Para verificar la instalación, abre una terminal o cmd y ejecuta: python --version. Si ves algo como Python 3.12.0, ¡todo está listo! También puedes probar el modo interactivo escribiendo python sin argumentos.

Tu primer programa: «Hola Mundo»

El programa más simple en Python es una línea: print(«Hola Mundo»). La función print() muestra texto en la consola. A diferencia de Python 2, en Python 3 los paréntesis son obligatorios.

Puedes ejecutar código de dos formas: escribiéndolo directamente en el intérprete interactivo (>>>), o guardándolo en un archivo con extensión .py y ejecutándolo con python archivo.py.

Experimenta con variaciones: print(«Hola», «Mundo») imprime con espacio automático, print(«Hola\nMundo») inserta un salto de línea, y print(«Hola» * 3) repite el texto tres veces.

El intérprete interactivo (REPL)

El REPL (Read-Eval-Print Loop) de Python te permite ejecutar código línea por línea y ver resultados inmediatos. Es perfecto para experimentar, probar ideas y aprender. Inícialo escribiendo python en tu terminal.

Dentro del REPL puedes hacer cálculos, probar funciones, explorar módulos con dir(), y obtener ayuda con help(). Para salir, escribe exit() o presiona Ctrl+Z (Windows) / Ctrl+D (Mac/Linux).

El prompt >>> indica que estás dentro de Python, mientras que C:\> o $ indican la terminal del sistema. No los confundas.

Editores y entorno de desarrollo

Aunque puedes escribir Python en cualquier editor de texto, usar un buen IDE mejora enormemente tu productividad. VS Code con la extensión de Python es la opción más popular: ofrece autocompletado, depuración, resaltado de sintaxis y control de versiones integrado.

Otras alternativas incluyen PyCharm (potente IDE para proyectos profesionales), Thonny (excelente para principiantes, muestra cómo funciona la memoria) e IDLE (viene instalado con Python, ligero y funcional).

Como buena práctica, crea una carpeta dedicada para tus proyectos Python y organiza cada ejercicio en su propio archivo .py.

Errores comunes y soluciones

Error 1: «Python no se reconoce como comando». Causa: no marcaste «Add Python to PATH». Solución: reinstala Python marcando esa casilla, o agrega manualmente la ruta a las variables de entorno del sistema.

Error 2: Escribir print «Hola» sin paréntesis. En Python 3, print() es una función y necesita paréntesis. En Python 2 funcionaba sin ellos, pero Python 2 dejó de recibir soporte en 2020.

Error 3: Confundir la indentación. Python usa espacios para agrupar bloques de código. Mezclar tabs con espacios causa un IndentationError. Configura tu editor para convertir tabs a espacios (4 espacios por nivel es el estándar).

Ejemplo Paso a Paso

Sigue estos pasos para comprender el concepto en la práctica:

  1. Paso 1: Crea un archivo llamado saludo.py en tu editor favorito.
  2. Paso 2: Escribe un comentario: # Mi primer programa en Python — los comentarios con # son ignorados por el intérprete.
  3. Paso 3: Agrega nombre = input('¿Cómo te llamas? ') — la función input() captura texto del teclado.
  4. Paso 4: Escribe print('Hola, ' + nombre + '! Bienvenido a Python.') — el operador + concatena cadenas.
  5. Paso 5: Guarda el archivo, abre la terminal en esa carpeta y ejecuta: python saludo.py.
Resultado esperado: Si escribes «Ana», verás: Hola, Ana! Bienvenido a Python.
