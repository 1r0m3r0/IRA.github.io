Explicación Detallada

Variables en Python

Las variables son nombres que asociamos a valores en memoria. Python usa tipado dinámico: no necesitas declarar el tipo explícitamente, el intérprete lo infiere al asignar el valor. Cuando escribes edad = 25, Python crea una variable edad de tipo int.

Los nombres de variables deben empezar con una letra o guión bajo, seguidos de letras, números o guiones bajos. Son case-sensitive: nombre y Nombre son variables distintas. La convención en Python es usar snake_case (palabras separadas por guión bajo).

A diferencia de otros lenguajes, las variables en Python son referencias a objetos. Al asignar b = a, ambas variables apuntan al mismo objeto en memoria.

Tipos de datos básicos

Python tiene tipos incorporados para cada necesidad: int (enteros: 42, -3, 0), float (decimales: 3.14, -0.5, 1e10), str (cadenas: «Hola», 'Python'), bool (True/False), list ([1,2,3]), tuple ((1,2,3)), dict ({'a': 1}) y set ({1,2,3}).

Usa type(variable) para conocer el tipo de cualquier valor. Esto es muy útil al depurar o cuando trabajas con datos de fuentes externas. Por ejemplo, type(«Hola») devuelve .

Los tipos int y float son inmutables: al modificarlos, se crea un nuevo objeto. Las listas y diccionarios son mutables: se modifican en el mismo lugar en memoria.

Operadores aritméticos

Python soporta: + (suma), - (resta), * (multiplicación), / (división → siempre float), // (división entera), % (módulo/resto), ** (potencia). Ejemplos: 10 / 3 = 3.3333, 10 // 3 = 3, 10 % 3 = 1, 2 ** 3 = 8.

El orden de operaciones sigue PEMDAS: Paréntesis → Exponentes → Multiplicación/División → Suma/Resta. Las operaciones con paréntesis se evalúan primero, de adentro hacia afuera.

La división entre cero lanza ZeroDivisionError. Siempre verifica que el divisor no sea cero antes de dividir.

Errores frecuentes con tipos

TypeError: ocurre al mezclar tipos incompatibles. «5» + 3 lanza «can only concatenate str (not int) to str». Solución: convierte usando int(«5») o str(3).

NameError: aparece cuando usas una variable no definida. print(x) sin haber creado x antes lanza «name 'x' is not defined». Siempre define las variables antes de usarlas.

Cuidado con input(): siempre devuelve str. Si necesitas un número, debes convertirlo: int(input('Edad: ')). Olvidar esto causa TypeError al hacer operaciones matemáticas.

Buenas prácticas

Usa nombres descriptivos: edad_usuario en vez de e, total_con_iva en vez de t. El código se lee muchas más veces de las que se escribe: invierte tiempo en hacerlo legible.

Constantes (valores fijos) se nombran en MAYÚSCULAS: PI = 3.14159, IVA = 0.16. Aunque Python no impide modificarlas, esta convención comunica la intención a otros programadores.

Mantén las variables cerca de donde se usan. Declararlas al inicio del archivo sin contexto dificulta la lectura. Sigue el principio de ámbito mínimo.

Asignación múltiple e intercambio

Python permite asignar múltiples variables en una línea: a, b, c = 1, 2, 3. También puedes intercambiar valores sin variable temporal: a, b = b, a. Esto funciona porque Python evalúa primero todo el lado derecho.

La asignación aumentada combina operador y asignación: x += 5 equivale a x = x + 5. Funciona con -=, *=, /=, //=, %=, **=. Es más conciso y legible.

Puedes ignorar valores con guión bajo: _, b = (1, 2). Esto es útil al desempaquetar tuples donde solo te interesan algunos elementos.

Ejemplo Paso a Paso

Sigue estos pasos para comprender el concepto en la práctica:

  1. Paso 1: Crea un archivo calculadora_area.py.
  2. Paso 2: Define PI = 3.14159 como constante (convención mayúscula).
  3. Paso 3: Solicita el radio al usuario y conviértelo a float: radio = float(input('Radio del círculo: ')).
  4. Paso 4: Calcula el área: area = PI * radio ** 2.
  5. Paso 5: Muestra el resultado con formato: print(f'Área: {area:.2f}').
Resultado esperado: Con radio = 5: Área: 78.54. Sin la conversión a float, ¡obtendrías un TypeError!
