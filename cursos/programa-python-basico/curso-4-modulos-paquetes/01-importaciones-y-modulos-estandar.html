El poder de la biblioteca estándar de Python

Módulo 1 de 12 (0%)
💡 Piénsalo así: Los módulos estándar de Python son como una biblioteca pública gigante. No tienes que escribir todo desde cero: ya hay libros (módulos) sobre matemáticas (math), fechas (datetime), números aleatorios (random), etc. Solo importas lo que necesitas: "import math" es como pedir prestado el libro de matemáticas. "from math import sqrt" es como fotocopiar solo la página que necesitas.
