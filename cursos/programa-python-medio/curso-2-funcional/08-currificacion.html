Currificación

Transforma f(a,b,c) en f(a)(b)(c) ” funciones que recuerdan

🍸 Piénsalo así: La currificación es como pedir un café en varias capas. No dices "quiero un café con leche descafeinado con hielo" de golpe. Primero pides "café", luego "con leche", luego "descafeinado", luego "con hielo". Cada paso fija una opción y te devuelve un menú más específico. f(a,b,c) currificado es f(a) que devuelve g(b) que devuelve h(c). Cada llamada "recuerda" los argumentos anteriores.

Constructor de Funciones Currificadas

Paso a paso: transforma f(a,b,c) = a + b * c

f(a, b, c) = a + b * c # Forma normal (sin currificar) resultado = f(2, 3, 4) # 2 + 3*4 = 14
💡 Currificación = transformar función de múltiples argumentos en cadena de funciones de un argumento. toolz.curry lo hace automáticamente.
