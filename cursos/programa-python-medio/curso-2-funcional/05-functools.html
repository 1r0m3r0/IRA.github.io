functools

partial, lru_cache, reduce — herramientas funcionales

🧰 Piénsalo así: functools es como un juego de destornilladores de precisión. partial es un destornillador que ya viene ajustado: siempre aprietas tornillos de estrella del tamaño 3. lru_cache es como una libreta de notas junto a la máquina: si ya calculaste 37×42, miras en la libreta en vez de calcular otra vez. reduce es como doblar una sábana entre dos: empiezas por una esquina y pliegas hasta el final.

Dashboard de functools

Explora cada herramienta:

from functools import partial # Fijamos el argumento base potencia = partial(pow, 2) print(potencia(3)) # 2^3 = 8 print(potencia(5)) # 2^5 = 32 # También con argumentos nombrados saludar = partial(print, "¡Hola!") saludar("Mundo") # ¡Hola! Mundo
💬 partial fija argumentos, lru_cache cachea resultados, reduce pliega secuencias. functools hace tu código funcional más expresivo.
