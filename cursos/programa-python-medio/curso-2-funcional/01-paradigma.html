Paradigma Funcional vs Imperativo

Dos formas de pensar, un mismo resultado

🗺ï¸ Piénsalo así: Imperativo es como dar direcciones paso a paso: "gira a la izquierda, camina 100m, gira a la derecha...". Funcional es como dar una receta de cocina: "toma huevos, mézclalos con harina, hornea 30min". La receta (función pura) siempre da el mismo resultado con los mismos ingredientes. Comparador Lado a Lado

Mismo problema resuelto en ambos paradigmas:

# IMPERATIVO nums = [1, 2, 3, 4, 5] resultado = [] for n in nums: if n % 2 == 0: resultado.append(n * 2) print(resultado)
# FUNCIONAL nums = [1, 2, 3, 4, 5] resultado = list( map(lambda n: n * 2, filter(lambda n: n % 2 == 0, nums)) ) print(resultado)

¿Qué paradigma crees que es más declarativo (qué hacer vs cómo hacerlo)?

💬 El paradigma funcional se enfoca en qué resultado queremos (declarativo), mientras el imperativo describe cómo llegar (paso a paso).
