Iteradores Personalizados

Haz que cualquier objeto funcione con for...in

📖 Piénsalo así: Un iterador es como un marcapáginas. El libro (objeto iterable) tiene páginas. El marcapáginas (iterador) recuerda dónde vas. Cada vez que pasas la página (llamas a next()), avanzas. Cuando llegas al final (StopIteration), el libro se acabó. __iter__ crea el marcapáginas, __next__ pasa la página.

Constructor de Iteradores

Selecciona un iterador personalizado y recórrelo paso a paso:

class ContadorRegresivo: def __init__(self, n): self.n = n def __iter__(self): return self def __next__(self): if self.n <= 0: raise StopIteration self.n -= 1 return self.n + 1
Paso: 0
💡 Presiona "next()" para iterar paso a paso...
💬 __iter__() devuelve el iterador. __next__() devuelve el siguiente valor o lanza StopIteration. Así funciona for...in por dentro.
