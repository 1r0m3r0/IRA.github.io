Pattern Matching

match/case — el switch de Python con superpoderes

🗂️ Piénsola así: match/case es como un clasificador inteligente de correo. No solo miras el sobre (el tipo), sino también su contenido (estructura). "Si es una carta con sello extranjero, ponla en la bandeja A; si es un paquete cuadrado de menos de 2kg, en la B; si es una tarjeta postales de París..." Puedes filtrar por forma, peso, origen. ¡Eso es match/case!

Juego de Pattern Matching

Dado el valor, elige el patrón match/case correcto:

valor = ("GET", "/users", {"id": 5})

💬 match/case desestructura el valor y compara patrones. Puedes emparejar tuplas, listas, dicts, clases y más.
