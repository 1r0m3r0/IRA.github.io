Descriptores

Controla cómo se accede y modifica cada atributo

🛂 Piénsalo así: Un descriptor es como un portero de discoteca. Cuando alguien quiere entrar (asignar un valor), el portero verifica: "¿Tienes más de 18? ¿Estás en la lista? ¿Traes identificación?" Si no cumples, no pasas. Así @PositiveNumber verifica que el valor sea positivo antes de aceptarlo. __get__ es "déjame ver", __set__ es "déjame entrar", __delete__ es "déjame salir".

Constructor de Descriptores

Prueba el descriptor @PositiveNumber que solo acepta valores positivos:

💡 El descriptor PositiveNumber solo permite valores > 0. Intenta con 5, -3, 0, 100...
class PositiveNumber: def __get__(self, obj, objtype): return obj.__dict__[self.name] def __set__(self, obj, value): if value <= 0: raise ValueError("¡Solo números positivos!") obj.__dict__[self.name] = value def __set_name__(self, owner, name): self.name = f"_{name}"
💬 Los descriptores controlan el acceso a atributos mediante __get__, __set__, __delete__. Se usan en @property, @classmethod, @staticmethod.
