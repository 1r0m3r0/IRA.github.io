Enumeraciones (Enum)

Constantes con identidad propia y superpoderes

🏁 Piénsalo así: Un Enum es como los botones de una máquina expendedora. Cada botón (A1, A2, B1) representa un producto único. No puedes pulsar "A1.5" porque no existe. Los botones tienen nombre (A1) y valor (unas patatas). Así Enum da nombre a constantes relacionadas: Color.ROJO = 1, Color.VERDE = 2. Nunca usarás "1" suelto porque siempre tendrás Color.ROJO.

Constructor de Enums

Selecciona un Enum para ver sus miembros, nombres y valores:

from enum import Enum class DiaSemana(Enum): LUNES = 1 MARTES = 2 MIERCOLES = 3 JUEVES = 4 VIERNES = 5 SABADO = 6 DOMINGO = 7
NombreValortype()
DiaSemana.LUNES1<enum 'DiaSemana'>
DiaSemana.VIERNES5<enum 'DiaSemana'>
💡 Presiona para ver por qué Enum es mejor que constantes sueltas.
💬 Enum agrupa constantes relacionadas. Cada miembro tiene .name y .value. auto() asigna valores automáticos.
