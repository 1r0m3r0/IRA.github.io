Generic, Protocol, Literal, TypedDict — tipos de otro nivel

🧬 Piénsalo así: Los genéricos (Generic[T]) son como un molde de galletas ajustable. Un molde "estrella" siempre hace estrellas, pero con Generic[T] decides de qué material: List[int], List[str], List[User]. El molde es el mismo, el ingrediente cambia. Protocol es como una "receta": si tienes los ingredientes (métodos), eres válido sin necesidad de heredar (duck typing estático).

Juego de Tipos Genéricos

Completa la firma con el type hint correcto:

def primera(lista: List[__]) -> __: return lista[0]
