Type Hints y mypy

Escribe código autodocumentado que mypy verifica

📋 Piénsalo así: Los type hints son como las etiquetas de un archivador. Cada carpeta (función) tiene una etiqueta que dice "aquí van documentos A (str), aquí documentos B (int), y de aquí sale un resumen (bool)". No afectan cómo guardas, pero cualquiera que abra el archivador sabrá qué va dónde. ¡Y mypy es el archivero que revisa que todo esté en su sitio!
