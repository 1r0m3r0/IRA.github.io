Context Managers

Gestiona recursos con with y olvídate de limpiar

🏨 Piénsalo así: Un context manager es como un hotel con recepción. Llegas (__enter__), te dan la llave de la habitación (el recurso), disfrutas tu estancia (ejecutas código), y al irte (__exit__) ellos limpian, cambian sábanas y cierran la puerta. Nunca olvidas devolver la llave porque el hotel se encarga. ¡Así es with open("file") as f!

Simulador de Context Managers

Elige un recurso para gestionar con with:

with open("datos.txt", "r") as archivo: contenido = archivo.read() print(contenido) # ⛔ archivo.close() automático
💡 Presiona "Ejecutar with" para ver el flujo __enter__ → código → __exit__
💬 with statement llama a __enter__ al inicio y __exit__ al final, incluso si hay errores. El recurso siempre se libera.

🏅 Administrador de Recursos 🏅

¡Dominas la gestión automática de recursos! Tu código nunca tendrá fugas de memoria o archivos abiertos.
