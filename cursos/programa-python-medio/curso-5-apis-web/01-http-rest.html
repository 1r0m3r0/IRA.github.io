HTTP y REST: El Lenguaje de la Web

GET, POST, PUT, DELETE ” los verbos de Internet

💡 Piéndalo así: HTTP es como el servicio postal de Internet. Tú envías una carta (request) con un método: GET es como "quiero ver el catálogo", POST es "quiero comprar algo nuevo", PUT es "cambio mi dirección", DELETE es "cancelo mi suscripción". REST es el formato estandarizado de las direcciones (URLs) para que el cartero sepa exactamente a dónde ir.
