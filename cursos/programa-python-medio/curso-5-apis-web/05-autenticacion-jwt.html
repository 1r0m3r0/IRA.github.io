Autenticación JWT

JSON Web Tokens ” la llave digital de tu API

💡 Piéndalo así: Un JWT es como un boleto de concierto con holograma. En el boleto está escrito: "Ana, acceso VIP, 20 de junio" (payload). El holograma (firma digital) garantiza que el boleto no fue falsificado. El servidor confía en el boleto porque puede verificar el holograma con su llave secreta, sin necesidad de buscar en una base de datos quién eres.

Selecciona la parte del JWT que contiene la información del usuario:

HEADER: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9
PAYLOAD: eyJzdWIiOiIxMjM0NTY3ODkwIiwibmFtZSI6IkFuYSIsImlhdCI6MTUxNjIzOTAyMn0
SIGNATURE: SflKxwRJSMeKKF2QT4fwpMeJf36POk6yJV_adQssw5c
