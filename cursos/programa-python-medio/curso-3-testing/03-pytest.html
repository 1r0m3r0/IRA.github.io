pytest

El framework moderno: assert simple, fixtures, parametrize

🚀 Piénsalo así: pytest es a unittest como un dron a un coche. unittest es el coche: sólido, conocido, pero pesado (clases, setUp, tearDown). pytest es el dron: ligero, ágil, con superpoderes. Usa assert nativo de Python (sin self.assertEqual), fixtures en vez de setUp, y parametrize para probar múltiples casos en una línea. ¡Menos código, más potencia!

Conversor unittest → pytest

Mira la diferencia — mismo test, menos código:

# unittest (verboso) import unittest class TestCalc(unittest.TestCase): def setUp(self): self.calc = Calculadora() def test_suma(self): self.assertEqual( self.calc.suma(2, 3), 5 ) def tearDown(self): del self.calc
# pytest (elegante) def test_suma(): calc = Calculadora() assert calc.suma(2, 3) == 5
💡 assert simple de Python. Sin clases, sin self., sin setUp.
💬 pytest usa assert nativo (no métodos especiales). Fixtures reemplazan setUp. parametrize genera múltiples casos.
