Filosofía de Testing y TDD

Red-Green-Refactor ” el ciclo que transforma tu código

🚦 Piénsalo así: TDD es como un semáforo para tu código. Rojo (RED): escribes un test que falla ” el semáforo está en rojo, no puedes pasar. Verde (GREEN): escribes el código mínimo para que el test pase ” semáforo en verde, avanzas. Refactor (REFACTOR): mejoras el código sin cambiar el comportamiento ” como poner el semáforo en ámbar mientras limpias la intersección. Rojo â†’ Verde â†’ Refactor. Una y otra vez.
