CI/CD con GitHub Actions

Automatiza lint, test, coverage y deploy con un solo push

🤖 Piénsalo así: CI/CD es como un mayordomo robot que cuida tu código 24/7. Cada vez que haces push (llegas a casa), el mayordomo (GitHub Actions) automáticamente: 1) Revisa que tu ropa esté limpia (lint), 2) Prueba que todo funcione (tests), 3) Mide el porcentaje de cobertura (coverage), 4) Si todo está bien, publica tu código (deploy). Y si algo falla, te manda un mensaje: "¡Oye, la camisa tiene una mancha!"

Pipeline CI/CD completo ” haz clic en cada paso:
