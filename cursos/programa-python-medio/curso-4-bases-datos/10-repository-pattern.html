Repository Pattern: Separando la Persistencia

Tu código no debería saber si usas SQLite o MongoDB

💡 Piéndalo así: El patrón repositorio es como el mostrador de atención de una biblioteca. Tú no entras al depósito a buscar libros (la base de datos). Le pides al bibliotecario: "dame el libro X" o "guarda este libro". Da igual si los libros están en estantes, cajas o una sala digital — el mostrador (repositorio) es siempre la misma interfaz.

Empareja cada método del repositorio con su descripción:

→Elimina una entidad
→Obtiene una entidad por ID
→Devuelve todas las entidades
→Guarda o actualiza
Haz clic en un método y luego en su descripción para emparejarlos.
