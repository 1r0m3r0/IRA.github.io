Alembic: Migraciones de Base de Datos

Git para tu esquema de base de datos

💡 Piéndalo así: Alembic es como un mapa de versiones para tu edificio. Cuando construyes una casa (tu BD), a veces añades un cuarto (una columna), cambias una ventana (modificas un tipo) o tiras una pared (eliminas una tabla). Alembic registra cada cambio como una versión. Si algo sale mal, puedes volver a la versión anterior, como git checkout pero para tu base de datos.

Ordena el flujo de trabajo de Alembic (arrastra en orden correcto):

A alembic revision --autogenerate -m "descripcion"
B alembic upgrade head
C alembic init alembic
D alembic history
Selecciona los pasos en el orden correcto del flujo de Alembic.
