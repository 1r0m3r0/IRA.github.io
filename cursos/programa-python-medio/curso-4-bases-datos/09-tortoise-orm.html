Tortoise-ORM: ORM Asíncrono para Python

Un ORM que nada en aguas async

💡 Piéndalo así: Tortoise-ORM es como un barco con múltiples botes salvavidas. Mientras SQLAlchemy es un barco grande que hace todo en orden (síncrono), Tortoise lanza varios botes al mismo tiempo (asíncrono). Cada consulta es un bote que va y viene sin esperar a los demás. Esto lo hace perfecto para FastAPI, donde quieres atender muchos usuarios simultáneamente.

Traduce este modelo SQLAlchemy a Tortoise-ORM: Elige la opción correcta.

// SQLAlchemy:
class Usuario(Base):
  __tablename__ = "usuarios"
  id = Column(Integer, primary_key=True)
  nombre = Column(String(100))
