09. CREATE TRIGGER

Curso 4 Modulo 9/12 PostgreSQL 19
Progreso del curso 0/12
Programa SQL Medio 0/72 - 0%

Automatiza acciones con disparadores

Los TRIGGERs ejecutan funciones automaticamente. Pueden ser BEFORE, AFTER o INSTEAD OF.

CREATE TRIGGER actualizar_timestamp BEFORE UPDATE ON empleados FOR EACH ROW EXECUTE FUNCTION set_fecha_modificacion();

FOR EACH ROW: por cada fila. FOR EACH STATEMENT: por sentencia.

💡 Sensor de movimiento

Un TRIGGER se activa automaticamente ante eventos INSERT/UPDATE/DELETE. Como una luz que se enciende al entrar.

🎲 Constructor de Triggers

Configura cada parte del TRIGGER:

CREATE TRIGGER ________ ________ ________ ON ________ FOR EACH ROW EXECUTE FUNCTION ________;
