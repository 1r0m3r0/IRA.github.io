05. REPEATABLE READ / SERIALIZABLE

Curso 5 Modulo 5/12 PostgreSQL 19
Progreso del curso 0/12
Programa SQL Medio 0/72 - 0%

Niveles avanzados de aislamiento

REPEATABLE READ: misma vista durante toda la transaccion. Previene dirty reads y non-repeatable reads.

SERIALIZABLE: ejecuta como si fueran secuenciales, una tras otra. Maximo aislamiento.

SET TRANSACTION ISOLATION LEVEL REPEATABLE READ; BEGIN; SELECT * FROM productos; -- Misma vista siempre COMMIT;

🎲 Una partida de ajedrez congelada

REPEATABLE READ congela los datos que ves durante toda la transaccion. SERIALIZABLE es como jugar ajedrez por turnos: una transaccion a la vez.
