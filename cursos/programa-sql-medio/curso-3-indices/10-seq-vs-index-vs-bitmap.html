⚖️ Seq Scan vs Index Scan vs Bitmap

Los 3 métodos de acceso — cuándo usa cada uno PostgreSQL

💡 Piénsalo así: Seq Scan = leer todo el libro página por página (bueno si buscas el 80% del libro). Index Scan = usar el índice para ir a páginas específicas (bueno para búsquedas precisas). Bitmap Scan = marcar con post-its varias páginas y luego ir a todas (bueno para combinar condiciones). Cada método tiene su momento.
