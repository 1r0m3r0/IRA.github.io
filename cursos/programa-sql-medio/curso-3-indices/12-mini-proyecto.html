🏆 Mini-Proyecto: Optimiza E-commerce

Integra todo lo aprendido sobre índices para optimizar una BD real

💡 Piénsalo así: Te contratan como DBA de un e-commerce que tiene 500k pedidos, 100k clientes y 50k productos. Las consultas están lentas. Tu misión: diagnosticar con EXPLAIN, crear los índices adecuados (B-tree, compuestos, parciales, covering), y medir la mejora. ¡Salva el negocio!

📋 Proyecto Final: Optimización Integral

Completa las tareas para ganar tu insignia de optimización:

CREATE INDEX idx_pedidos_fecha ON pedidos (fecha);
CREATE INDEX idx_pedidos_cliente_fecha ON pedidos (cliente_id, fecha);
CREATE INDEX idx_productos_activos ON productos (precio) WHERE activo = true;
CREATE INDEX idx_productos_catalogo ON productos (categoria) INCLUDE (precio, stock);
