Piensalo asi: Elegir el grafico correcto es como elegir la herramienta adecuada para cada trabajo. No usarias un martillo para atornillar ni un destornillador para clavar. El box plot es como una radiografia de tus datos; el dot plot es como una lluvia de puntos; el stem-and-leaf es un arbol que muestra cada valor; y el heatmap es como un mapa de calor de una ciudad.
