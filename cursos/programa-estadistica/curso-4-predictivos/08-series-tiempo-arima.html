⏱️ ARIMA y GARCH

AR, MA, ARIMA, GARCH, estacionariedad, Box-Jenkins

ARIMA GARCH Box-Jenkins
Módulo 8 de 12
💡 Piénsalo así: Las series temporales son como el ritmo cardíaco. AR captura cómo el latido actual depende del anterior (memoria). MA captura cómo reacciona a shocks recientes (sorpresas). ARIMA combina ambos + tendencia. GARCH modela la volatilidad: momentos de calma vs tormenta, como un corazón que se acelera o se calma.
Componentes de ARIMA y GARCH

🔄 AR (Autorregresivo)

El valor actual depende de valores pasados. AR(p): Y_t = φ₁Y_{t-1} + ... + φ_pY_{t-p} + ε_t. Usa PACF para identificar el orden p. Memoria larga del proceso.

📊 MA (Medias Móviles)

El valor actual depende de errores pasados. MA(q): Y_t = ε_t + θ₁ε_{t-1} + ... + θ_qε_{t-q}. Usa ACF para identificar el orden q. Memoria corta de shocks.

📦 ARIMA(p,d,q)

Combina AR + MA + diferenciación (d). La d indica cuántas diferencias se necesitan para hacer la serie estacionaria. Box-Jenkins: Identificar → Estimar → Diagnosticar → Predecir.

🌊 GARCH(p,q)

Modela la varianza condicional (volatilidad). GARCH: σ²_t = ω + αε²_{t-1} + βσ²_{t-1}. Captura clusters de volatilidad. Esencial en finanzas para Value at Risk y trading.
