Los gráficos de control son tus indicadores: si una medición sale de los límites, sabes que algo cambió y debes intervenir.
Herramientas de Control de Calidad

📊 Gráficos X-bar y R

X-bar monitorea la media del proceso; R monitorea la variabilidad (rango). Se usan juntos para variables continuas con subgrupos de tamaño constante.

📈 Gráficos p, np, c, u

p = proporción de defectos, np = número de defectos, c = conteo de defectos por unidad constante, u = defectos por unidad variable. Para datos de atributos.

⚙️ Índices Cp y Cpk

Cp mide la capacidad potencial (anchura de especificaciones vs. variabilidad del proceso). Cpk mide la capacidad real, considerando si el proceso está centrado.

🎯 Six Sigma

Metodología DMAIC (Define, Measure, Analyze, Improve, Control) para reducir defectos a 3.4 ppm. Usa herramientas estadísticas para mejorar procesos.
