Piensalo asi: El analisis de poder es como decidir cuantos pescados debes atrapar para saber si un lago tiene una especie particular. Si el lago tiene muchos peces (efecto grande), con pocos atrapes basta. Si la especie es rara (efecto pequeno), necesitas muchos mas. El poder es tu confianza en que, si la especie esta ahi, la vas a encontrar. No quieres irte con las manos vacias pensando "no hay peces" cuando solo no pescaste suficiente.
Fundamentos de Poder Estadistico

Componentes del Poder

Poder = f(alfa, tamano del efecto, tamano muestral). Al aumentar cualquiera de los dos ultimos (o alfa), el poder aumenta. Tipicamente se busca 80%.

Tamano del Efecto (Cohen d)

d = (M? - M?) / DE. Estandariza la diferencia. d = 0.2: pequeno, 0.5: mediano, 0.8: grande. Permite comparar efectos entre estudios.

Calculo de Tamano Muestral

n = f(alfa, poder, d). Para un poder de 80% y alfa 0.05, n por grupo = 393 (d pequeno), 64 (mediano), 26 (grande) para prueba t bilateral.

G*Power

Software gratuito para analisis de poder. Soporta t, F, chi-cuadrado, correlaciones, proporciones y modelos lineales. Ampliamente usado en ciencias sociales.
