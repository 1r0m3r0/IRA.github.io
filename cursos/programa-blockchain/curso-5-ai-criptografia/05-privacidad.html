PRIVACIDAD ON-CHAIN

Transacciones privadas, compliance y tecnologías de ofuscación

TEE · MPC Aztec · Railgun FHE
Piensa así: la privacidad on-chain es como tener una cuenta bancaria donde nadie puede ver tus transacciones, pero el banco sabe que cumples la ley. Usas criptografía avanzada (TEE, MPC, FHE) para probar que eres compliance sin exponer tu historial financiero.

Objetivos de este módulo

  • Entender las tecnologías de privacidad on-chain y sus trade-offs
  • Conocer TEE, MPC, FHE y cómo se aplican en blockchain
  • Analizar el balance entre privacidad y compliance regulatorio

Intuición

La privacidad on-chain usa tres tecnologías principales: TEE (ejecución en entorno aislado de hardware), MPC (cálculo entre múltiples partes sin revelar datos), y FHE (cálculo sobre datos encriptados). Cada una tiene su balance entre seguridad, velocidad, y usabilidad.

Paso a paso

1. El usuario envía transacción encriptada. 2. El protocolo de privacidad procesa la tx usando TEE/MPC/FHE. 3. La transacción se valida sin revelar datos. 4. El resultado se publica on-chain. 5. Solo el usuario y las partes autorizadas ven los detalles.

Ejemplo concreto

TEE: Intel SGX — cálculos dentro de un enclave aislado. MPC: red de nodos que computan datos compartidos sin revelarlos. FHE: cálculos sobre datos encriptados — el futuro de la privacidad. Aztec usa ZK + privacidad nativa en L2.

Error común

Pensar que privacidad total es incompatible con compliance. Tecnologías como "selective disclosure" permiten revelar solo ciertos datos a reguladores cuando sea necesario. Railgun usa ZK-proofs con privacy pools para compliance.

Relevancia actual

Aztec Network: L2 con privacidad nativa. Railgun: privacy pools con compliance. Secret Network: smart contracts privados con TEE. El mercado de privacidad on-chain crece 3x anual desde 2024.

Conexión

La privacidad se construye sobre ZK-proofs (04), se conecta con DIDs (06) para identidad, y con compliance (10) para cumplimiento regulatorio.

TEE (Trusted Execution Environment)

Ejecuta código en un entorno aislado del hardware (Intel SGX, AMD SEV). Ni el sistema operativo puede ver los datos internos. Secret Network usa TEE para smart contracts privados. Rápido pero requiere confianza en el fabricante del hardware.
