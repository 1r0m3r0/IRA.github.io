PAGOS M2M

Machine-to-Machine: la economía de agentes autónomos

M2M Economy x402 · ERC-402 Gas Sponsored
Piensa así: los pagos M2M son como el dinero que se transfiere solo entre máquinas. Tu nevera paga a la red eléctrica cuando consume. Tu coche paga al parking. Tu AI agent paga al LLM que usa. Todo sin humanos, todo en micro-pagos.

Objetivos de este módulo

  • Entender el concepto de pagos machine-to-machine en blockchain
  • Conocer el estándar ERC-402/x402 y gas sponsorship
  • Simular micro-pagos entre agentes autónomos

Intuición

Los pagos M2M permiten que máquinas y AI agents se paguen entre sí sin intervención humana. Ejemplos: un AI agent paga a una API por datos, un vehículo autónomo paga peajes, un sensor IoT paga por almacenamiento. Todo en micro-transacciones on-chain.

Paso a paso

1. El agent solicitante (consumer) necesita un servicio. 2. El agent proveedor (provider) ofrece el servicio con precio. 3. El consumer firma una transacción de pago. 4. El provider entrega el servicio. 5. La transacción se liquida on-chain en segundos.

Ejemplo concreto

Un AI agent necesita consultar un LLM para analizar un contrato. Envía $0.05 en ETH con una transacción x402. El LLM procesa la consulta y devuelve el resultado. El pago se liquida en la misma transacción. Todo autónomo.

Error común

Pensar que los pagos M2M requieren grandes cantidades. La realidad son micro-pagos: $0.001 a $0.10 por transacción. El gas debe ser ultra-bajo (L2s como Arbitrum u Optimism) para que sea viable. Las L2s hacen posible la economía M2M.

Relevancia actual

Se proyecta que para 2030 habrá 50,000 millones de dispositivos IoT conectados. Cada uno generando micro-transacciones. El mercado M2M podría alcanzar $1T+ para 2028. L2s como Arbitrum procesan >$1B diario en transacciones.

Conexión

Los pagos M2M son la base para AI agents (02), se conectan con privacidad (05) para pagos anónimos, y con stablecoins (C4-06) como medio de pago.

Ecosistema de Pagos M2M

x402
ERC-402: gas patrocinado por el proveedor del servicio.
Superfluid
Streaming de pagos: paga por segundo de uso de AI.
IoT Chains
IOTA, Helium: blockchains diseñadas para M2M e IoT.
L2s
Arbitrum, Optimism: gas ultra-bajo para micro-pagos.

x402 (ERC-402)

Estándar para pagos machine-to-machine donde el proveedor del servicio patrocina el gas. El consumer firma un mensaje EIP-712 y el provider incluye el pago en una transacción que paga el gas. Ideal para micro-pagos de AI agents.
