¿Qué es SQL y las BD Relacionales?

Módulo 1 Â· Fundamentos

Concepto

SQL (Structured Query Language) es el lenguaje universal para comunicarse con bases de datos relacionales. Piensa en una BD relacional como un conjunto de hojas de cálculo (tablas) que se conectan entre sí.

Analogía: Una base de datos relacional es como un archivero con carpetas. Cada carpeta (tabla) contiene fichas (filas) con información organizada en campos (columnas). SQL es el idioma que usas para pedirle al archivista que te traiga exactamente lo que necesitas.
