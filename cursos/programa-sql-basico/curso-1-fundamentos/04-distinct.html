  • Diferenciar DISTINCT de otras formas de filtrado

🧠 Intuición

DISTINCT es como el botón 'quitar duplicados'. Cuando tienes una lista con valores repetidos, DISTINCT te muestra cada valor una sola vez.

Imagina que preguntas a 100 personas de qué ciudad son. Sin DISTINCT obtienes 100 respuestas (muchas repetidas). Con DISTINCT obtienes solo las ciudades únicas.

Es útil para preguntas como '¿qué categorías de productos tenemos?' o '¿en qué ciudades hay clientes?'.

📝 Sintaxis DISTINCT

SELECT DISTINCT columna FROM tabla;

SELECT DISTINCT col1, col2 FROM tabla; — elimina duplicados basándose en la combinación de ambas columnas.

DISTINCT afecta a TODAS las columnas seleccionadas, no solo a una.

💻 Ejemplo Práctico

SELECT DISTINCT ciudad FROM clientes; — lista todas las ciudades sin repetir.

SELECT DISTINCT ciudad, pais FROM clientes; — combinaciones únicas de ciudad+país.

SELECT COUNT(DISTINCT categoria) FROM productos; — cuenta cuántas categorías diferentes hay.

⚠️ Errores Comunes

Pensar que DISTINCT se aplica solo a la primera columna: se aplica a TODAS las columnas del SELECT.

Usar DISTINCT cuando necesitas GROUP BY: son conceptos diferentes.

Olvidar que DISTINCT es costoso: ordena los datos internamente para eliminar duplicados.

🔍 Dato Curioso

PostgreSQL tiene también DISTINCT ON (columna) que es más específico.

DISTINCT y ORDER BY pueden combinarse, pero las columnas del ORDER BY deben estar en el SELECT.

Algunos SGBD tratan NULL como un valor DISTINCT, solo aparece una vez.

🎯 Concepto Clave

DISTINCT elimina filas duplicadas del resultado.

Afecta a la combinación de todas las columnas seleccionadas.

Es útil para catálogos, listas únicas y conteos de valores distintos.

Ejemplo Paso a Paso

-- Paso 1: Ver todas las categorías (con duplicados)
SELECT categoria FROM productos;
-- Resultado: Electronica, Electronica, Ropa, Ropa, Hogar

-- Paso 2: Solo categorías únicas
SELECT DISTINCT categoria FROM productos;
-- Resultado: Electronica, Ropa, Hogar

-- Paso 3: Contar valores distintos
SELECT COUNT(DISTINCT categoria) AS num_categorias FROM productos;

Concepto

DISTINCT elimina duplicados del resultado. Se coloca después de SELECT y antes de las columnas.

SELECT DISTINCT ciudad
FROM clientes;
Analogía: Como cuando haces una lista de invitados y tachas los nombres repetidos para que cada persona aparezca solo una vez.

Resumen del Módulo
