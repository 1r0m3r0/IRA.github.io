Valores Únicos con DISTINCT

Módulo 4 · Fundamentos

Concepto

DISTINCT elimina duplicados del resultado. Se coloca después de SELECT y antes de las columnas.

SELECT DISTINCT ciudad
FROM clientes;
Analogía: Como cuando haces una lista de invitados y tachas los nombres repetidos para que cada persona aparezca solo una vez.
