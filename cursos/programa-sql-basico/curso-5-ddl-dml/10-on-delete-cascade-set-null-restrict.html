🔗 ON DELETE CASCADE / SET NULL / RESTRICT

¿Qué pasa con los hijos cuando el padre desaparece?

💡 Piénsalo así: Cuando eliminas un cliente, ¿qué pasa con sus pedidos? CASCADE: elimina todo (el cliente y sus pedidos). SET NULL: los pedidos se quedan pero sin cliente asignado (como "pedido huérfano"). RESTRICT: no te deja eliminar el cliente si tiene pedidos (te obliga a limpiar primero). Es como decidir qué pasa con los archivos de un empleado cuando renuncia: ¿los borras (CASCADE), los dejas sin dueño (SET NULL) o no dejas que lo despidan hasta que resuelva sus proyectos (RESTRICT)?

FOREIGN KEY (cliente_id) REFERENCES clientes(id) ON DELETE CASCADE
