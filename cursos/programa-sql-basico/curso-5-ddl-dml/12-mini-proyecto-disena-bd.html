🏆 Mini-Proyecto: Diseña tu BD

Proyecto integrador — diseña el esquema completo de una red social

💡 Piénsalo así: Has aprendido todos los ladrillos (CREATE, ALTER, INSERT, UPDATE, DELETE) y las reglas (PK, FK, UNIQUE, CHECK, DEFAULT, NOT NULL, CASCADE). Ahora es momento de construir una CASA completa. En el mundo real, los DBA diseñan esquemas desde cero, definiendo tablas, relaciones y constraints antes de escribir una sola línea de datos.

Completa los 4 desafíos para obtener tu insignia de Diseñador de BD.

🏗️ Diseña una Red Social de Música

📌 Paso 1 · Tabla usuarios

Crea la tabla usuarios con: id (PK), nombre (NOT NULL), email (UNIQUE, NOT NULL), bio, fecha_registro (DEFAULT CURRENT_DATE).

📌 Paso 2 · Tabla canciones

Crea la tabla canciones con: id (PK), titulo (NOT NULL), artista (NOT NULL), genero, duracion_seg CHECK (duracion_seg > 0).

📌 Paso 3 · Tabla playlists (FK)

Crea la tabla playlists con: id (PK), nombre (NOT NULL), usuario_id (FK → usuarios(id) ON DELETE CASCADE).

📌 Paso 4 · Tabla playlist_canciones (M:M)

Crea la tabla playlist_canciones con FK a playlists y canciones, y PRIMARY KEY compuesta.

💬 Completa cada paso escribiendo la sentencia CREATE TABLE con los constraints indicados
