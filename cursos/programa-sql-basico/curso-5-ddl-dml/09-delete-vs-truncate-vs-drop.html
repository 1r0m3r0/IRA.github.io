⚔️ DELETE vs TRUNCATE vs DROP

Tres formas de eliminar — cada una con un poder diferente

💡 Piénsalo así: DELETE es como sacar libros específicos de un estante (con WHERE). TRUNCATE es como vaciar TODO el estante de golpe, pero el estante sigue ahí. DROP es como desmontar el estante entero y tirarlo a la basura. DELETE puede deshacerse (en transacción), TRUNCATE es más rápido pero menos flexible, DROP es definitivo (sin estructura).

DELETE: lento, con WHERE, preserva estructura, activa triggers.
TRUNCATE: rápido, sin WHERE, preserva estructura, reinicia contadores.
DROP: instantáneo, elimina estructura y datos.
