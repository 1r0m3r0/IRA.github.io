🔧 ALTER TABLE

Modifica la estructura de una tabla sin perder los datos existentes

💡 Piénsalo así: ALTER TABLE es como reformar tu casa. Puedes añadir una habitación nueva (ADD COLUMN), cambiar el tamaño de una ventana (ALTER COLUMN), o quitar una pared (DROP COLUMN). Lo mejor: NO tienes que demoler toda la casa y construir de nuevo. Los muebles (datos) que ya están dentro se conservan.

Comandos: ALTER TABLE nombre ADD COLUMN ..., ALTER TABLE nombre DROP COLUMN ..., ALTER TABLE nombre ALTER COLUMN ...

¿Qué aprenderás?

  • Añadir columnas con ALTER TABLE ADD
  • Modificar columnas con ALTER TABLE ALTER
  • Eliminar columnas con ALTER TABLE DROP
  • Entender las limitaciones de ALTER

🧠 Intuición

ALTER TABLE es como reformar tu casa: puedes añadir una habitación (columna), cambiar el tamaño (tipo de dato) o derribar una pared (eliminar columna).

A diferencia de CREATE que se hace una vez, ALTER se usa cuando la base de datos ya está en funcionamiento.

Es una operación delicada: modificar tablas con datos puede ser lento o imposible.

📝 Sintaxis ALTER

ALTER TABLE tabla ADD COLUMN columna tipo;

ALTER TABLE tabla ALTER COLUMN col TYPE nuevo_tipo;

ALTER TABLE tabla DROP COLUMN columna;

ALTER TABLE tabla RENAME COLUMN viejo TO nuevo;

💻 Ejemplo

ALTER TABLE productos ADD COLUMN descripcion TEXT;

ALTER TABLE productos ALTER COLUMN precio TYPE NUMERIC(12,2);

ALTER TABLE productos DROP COLUMN descripcion;

ALTER TABLE productos RENAME COLUMN nombre TO titulo;

⚠️ Errores

Eliminar una columna que es referenciada por una FK.

Cambiar tipo a uno incompatible con los datos existentes.

ALTER TABLE en tablas grandes puede ser muy lento y bloquear la tabla.

🔍 Dato

PostgreSQL soporta ALTER TABLE ... SET DEFAULT para añadir valor por defecto.

Algunos cambios de tipo requieren USING para convertir los datos existentes.

En PostgreSQL, ADD COLUMN es instantáneo (solo metadata).

🎯 Clave

ADD COLUMN → añade columna.

ALTER COLUMN → cambia tipo.

DROP COLUMN → elimina columna.

RENAME COLUMN → renombra.

Ejemplo Paso a Paso

-- Paso 1: Añadir columna
ALTER TABLE productos ADD COLUMN descripcion TEXT;

-- Paso 2: Modificar tipo
ALTER TABLE productos ALTER COLUMN precio TYPE NUMERIC(12,2);

-- Paso 3: Eliminar columna
ALTER TABLE productos DROP COLUMN descripcion;

-- Paso 4: Renombrar
ALTER TABLE productos RENAME COLUMN nombre TO titulo;

Resumen del Módulo

ALTER TABLE modifica la estructura de tablas existentes. ADD añade columnas, ALTER COLUMN cambia tipos, DROP elimina columnas. Es útil para evolucionar el esquema sin perder datos.
