🧠 Intuición

CREATE DATABASE es como comprar un terreno vacío. CREATE TABLE es como construir una casa en ese terreno, con habitaciones (columnas) para cada tipo de cosa que guardarás.

Sin CREATE no hay nada — es el primer paso de cualquier proyecto de base de datos.

DDL (Data Definition Language) incluye CREATE, ALTER, DROP y TRUNCATE.

📝 Sintaxis CREATE

CREATE DATABASE nombre;

CREATE TABLE nombre (columna tipo, columna tipo, ...);

Tipos comunes: INTEGER, VARCHAR(n), DECIMAL(p,s), DATE, BOOLEAN.

Las columnas se separan con comas (la última no lleva coma).

💻 Ejemplo

CREATE DATABASE tienda;

CREATE TABLE productos (id INTEGER, nombre VARCHAR(100), precio DECIMAL(10,2));

CREATE SCHEMA ventas; CREATE TABLE ventas.pedidos (...);

⚠️ Errores

Olvidar el punto y coma al final.

Poner coma después de la última columna.

Usar nombres reservados como ORDER o TABLE como nombre de tabla.

🔍 Dato

PostgreSQL tiene CREATE SCHEMA además de CREATE DATABASE.

Los nombres en SQL se convierten a minúsculas a menos que uses comillas dobles.

IF NOT EXISTS evita errores si ya existe.

🎯 Clave

CREATE DATABASE → crear BD.

CREATE TABLE → crear tabla.

Especifica tipos de datos.

Las columnas se separan con comas.
