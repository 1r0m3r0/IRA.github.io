🔗 UNION / UNION ALL

Combina resultados de múltiples consultas en un solo conjunto

💡 Piénsalo así: UNION es como mezclar dos listas de invitados pero eliminando los nombres repetidos ” si Juan está en ambas listas, solo aparece una vez. UNION ALL es como juntar las listas sin importar duplicados ” si Juan está dos veces, aparece dos veces. UNION ALL es más rápido porque no necesita hacer el trabajo extra de eliminar duplicados.

Regla de oro: ambas consultas deben tener EL MISMO número de columnas y tipos de datos compatibles.

¿Qué aprenderás?

  • Usar UNION para combinar resultados
  • Usar UNION ALL para conservar duplicados
  • Entender la diferencia entre UNION y UNION ALL
  • Combinar resultados de múltiples consultas

🧠 Intuición

UNION es como apilar dos listas una encima de otra. Si tienes empleados de Madrid y empleados de Barcelona, UNION te da todos.

UNION elimina DUPLICADOS, UNION ALL los conserva. UNION ALL es más rápido porque no hace el trabajo extra de eliminar repetidos.

Las consultas deben tener el MISMO número de columnas y tipos compatibles.

📝 Sintaxis

SELECT * FROM tabla1 UNION SELECT * FROM tabla2;

SELECT * FROM tabla1 UNION ALL SELECT * FROM tabla2;

Los nombres de columna vienen de la PRIMERA consulta.

ORDER BY al final de todo.

💻 Ejemplo

SELECT nombre, email FROM clientes_madrid UNION SELECT nombre, email FROM clientes_barcelona;

SELECT nombre FROM empleados_actuales UNION ALL SELECT nombre FROM empleados_historicos;

⚠️ Errores

Número diferente de columnas: error.

Tipos incompatibles: error.

ORDER BY en cada consulta (solo al final).

UNION puede ser lento en tablas grandes por la eliminación de duplicados.

🔍 Dato

UNION hace un DISTINCT implícito (ordena y elimina duplicados).

UNION ALL es más rápido y recomendado si sabes que no hay duplicados.

PostgreSQL optimiza UNION con hash o sort según el caso.

🎯 Clave

UNION = combina y elimina duplicados.

UNION ALL = combina sin eliminar.

Mismo número de columnas.

Tipos compatibles.

ORDER BY al final.

Ejemplo Paso a Paso

-- Paso 1: UNION elimina duplicados
SELECT ciudad FROM clientes_madrid UNION SELECT ciudad FROM clientes_barcelona;

-- Paso 2: UNION ALL conserva duplicados (más rápido)
SELECT nombre FROM empleados_2023 UNION ALL SELECT nombre FROM empleados_2024;

-- Paso 3: Con ORDER BY al final
SELECT nombre, total FROM enero UNION ALL SELECT nombre, total FROM febrero ORDER BY total DESC;
