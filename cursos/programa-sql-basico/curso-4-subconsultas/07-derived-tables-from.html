📦 Derived Tables (FROM)

Subconsultas en la cláusula FROM — una tabla temporal dentro de tu consulta

💡 Piénsalo así: Una derived table es como armar un rompecabezas intermedio antes de resolver el problema final. Primero creas una "tabla virtual" con los datos que necesitas (usando una subconsulta en FROM), y luego haces una consulta sobre esa tabla. Es como si anotaras resultados parciales en una hoja aparte y luego trabajaras con esa hoja.

La derived table SIEMPRE necesita un alias (AS nombre). Es como ponerle una etiqueta a tu tabla temporal para poder referenciarla.
