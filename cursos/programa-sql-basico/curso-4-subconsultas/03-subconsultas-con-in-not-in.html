📋 Subconsultas con IN / NOT IN

Filtrar por una lista de valores obtenida de otra tabla

💡 Piénsalo así: Tienes una lista de invitados VIP (subconsulta) y quieres saber quiénes de tus amigos están en esa lista. IN funciona como "dame todos los que están EN esta lista". NOT IN es lo contrario: "dame los que NO están en la lista negra".

La subconsulta devuelve múltiples filas (una columna), y el IN/NOT IN verifica si el valor está presente en ese conjunto.

¿Qué aprenderás?

  • Usar IN con subconsultas
  • Usar NOT IN con subconsultas
  • Manejar subconsultas de múltiples filas
  • Evitar el problema de NULL en NOT IN

🧠 Intuición

IN con subconsultas es como tener una lista dinámica. En vez de escribir IN (1, 2, 3), la subconsulta genera la lista automáticamente.

Perfecto para 'dame todos los clientes que han hecho pedidos' sin necesidad de JOIN.

NOT IN hace lo contrario: 'dame los que NO han hecho pedidos'.

📝 Sintaxis

SELECT * FROM tabla WHERE col IN (SELECT col2 FROM tabla2);

SELECT * FROM tabla WHERE col NOT IN (SELECT col2 FROM tabla2);

La subconsulta puede devolver múltiples filas.

La subconsulta devuelve una sola columna.

💻 Ejemplo

SELECT * FROM clientes WHERE id IN (SELECT cliente_id FROM pedidos); — clientes con pedidos.

SELECT * FROM productos WHERE id NOT IN (SELECT producto_id FROM ventas); — productos no vendidos.

⚠️ Errores

NOT IN con NULL en la subconsulta: el resultado SIEMPRE será vacío. Usa NOT EXISTS.

Olvidar que la subconsulta debe devolver UNA columna.

🔍 Dato

IN con subconsulta se optimiza internamente como un JOIN.

NOT EXISTS es más seguro que NOT IN porque maneja NULL correctamente.

🎯 Clave

IN = múltiples valores de subconsulta.

NOT IN es peligroso con NULL → usa NOT EXISTS.

La subconsulta devuelve una columna, varias filas.

Ejemplo Paso a Paso

-- Paso 1: IN con subconsulta
SELECT nombre FROM clientes WHERE id IN (SELECT cliente_id FROM pedidos);

-- Paso 2: NOT IN (cuidado con NULL)
SELECT nombre FROM productos WHERE id NOT IN (SELECT producto_id FROM ventas WHERE producto_id IS NOT NULL);

-- Paso 3: Alternativa segura con NOT EXISTS
SELECT nombre FROM productos p WHERE NOT EXISTS (SELECT 1 FROM ventas v WHERE v.producto_id = p.id);

Resumen del Módulo

IN con subconsultas crea listas dinámicas de valores. NOT IN es útil pero peligroso si hay NULL. Prefiere NOT EXISTS para exclusión cuando haya posibilidad de NULL en los resultados.
