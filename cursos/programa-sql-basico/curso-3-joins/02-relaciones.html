Relaciones 1:1, 1:M y M:M

Módulo 2 · Joins

Concepto

1:1 — un registro se relaciona con uno solo. 1:M — un registro se relaciona con muchos. M:M — muchos se relacionan con muchos (requiere tabla intermedia).

Analogía: 1:1 = cada persona tiene un pasaporte único. 1:M = una madre tiene muchos hijos. M:M = estudiantes y cursos: cada estudiante toma varios cursos, cada curso tiene varios estudiantes.
