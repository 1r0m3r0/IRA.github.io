Mini-Proyecto: Sistema de Pedidos

Módulo 12 Â· Joins

¿Qué aprenderás?

  • Aplicar todos los tipos de JOIN
  • Resolver consultas complejas de pedidos
  • Combinar múltiples tablas en una consulta
  • Usar JOINs en un escenario real

🧠 Intuición

Este mini-proyecto simula un sistema de pedidos real con clientes, productos, pedidos y detalle de pedidos. Usarás todos los tipos de JOIN.

Es el proyecto más completo del curso, integrando PK/FK, INNER/LEFT/Self-Join y agregaciones.

Al completarlo, estarás listo para modelar cualquier sistema de ventas.

📝 Proyecto

Diseñar tablas con PK y FK.

Usar INNER JOIN para consultas básicas.

LEFT JOIN para incluir todos los clientes.

Self-Join para jerarquías de productos.

Agregaciones con GROUP BY y JOIN.

💻 Consultas

Total gastado por cada cliente.

Productos más vendidos.

Clientes que nunca compraron.

Categorías con más productos.

⚠️ Desafíos

JOINs sin ON: producto cartesiano accidental.

LEFT JOIN convertido en INNER JOIN por WHERE.

No usar alias en consultas largas.

🔍 Dato

En sistemas reales, las consultas tienen 5-10 JOINs o más.

Saber JOINs bien es la habilidad más valorada en SQL.

🎯 Consejo

Dibuja el diagrama de tablas antes de escribir la consulta.

Empieza con 2 tablas y ve añadiendo.

Usa LEFT JOIN si no estás seguro del tipo.

Ejemplo Paso a Paso

-- Sistema de pedidos completo
SELECT c.nombre, COUNT(p.id) AS pedidos, SUM(p.total) AS gasto_total
FROM clientes c
LEFT JOIN pedidos p ON c.id = p.cliente_id
GROUP BY c.nombre
ORDER BY gasto_total DESC NULLS LAST;

-- Productos más vendidos
SELECT pr.nombre, SUM(dp.cantidad) AS vendidos
FROM productos pr
JOIN detalle_pedido dp ON pr.id = dp.producto_id
GROUP BY pr.nombre ORDER BY vendidos DESC LIMIT 10;
