Self-Join

Módulo 8 Â· Joins

¿Qué aprenderás?

  • Usar Self-Join para unir una tabla consigo misma
  • Aplicar Self-Join con relaciones jerárquicas
  • Usar alias para distinguir las copias de la tabla
  • Resolver problemas de empleados-jefe, categorías anidadas

🧠 Intuición

Self-Join es como un espejo: una tabla se mira a sí misma. Se usa para relaciones jerárquicas como empleados que tienen un jefe (que también es empleado).

Necesitas usar alias para distinguir la 'tabla de empleados' de la 'tabla de jefes', aunque sean la misma tabla física.

Es confuso al principio pero muy poderoso para datos jerárquicos.

📝 Sintaxis

SELECT a.col, b.col FROM tabla a JOIN tabla b ON a.id = b.padre_id;

Los alias (a, b) son OBLIGATORIOS en Self-Join.

Puedes usar cualquier tipo de JOIN (INNER, LEFT, etc.).

💻 Ejemplo

SELECT e.nombre AS empleado, j.nombre AS jefe FROM empleados e LEFT JOIN empleados j ON e.jefe_id = j.id;

SELECT c1.nombre AS cat, c2.nombre AS subcat FROM categorias c1 JOIN categorias c2 ON c1.id = c2.padre_id;

⚠️ Errores

Olvidar los alias: SQL no sabe a qué copia de la tabla te refieres.

Usar INNER JOIN y perder empleados sin jefe (usa LEFT JOIN).

Crear uniones cíclicas accidentales.

🔍 Dato

Self-Join se usa para listas de adyacencia en grafos.

PostgreSQL soporta WITH RECURSIVE para jerarquías más complejas.

Self-Join funciona con cualquier tipo de JOIN.

🎯 Clave

Self-Join = una tabla unida consigo misma.

Los alias son obligatorios.

Útil para jerarquías (empleado-jefe, categorías).

LEFT JOIN para no perder filas sin relación.

Ejemplo Paso a Paso

-- Paso 1: Self-Join básico (empleado - jefe)
SELECT e.nombre AS empleado, j.nombre AS jefe
FROM empleados e
LEFT JOIN empleados j ON e.jefe_id = j.id;

-- Paso 2: Categorías y subcategorías
SELECT c1.nombre AS principal, c2.nombre AS subcategoria
FROM categorias c1
INNER JOIN categorias c2 ON c1.id = c2.padre_id;

Concepto

Self-Join es unir una tabla consigo misma usando alias diferentes. Es útil para jerarquías (empleados con jefes) o comparaciones internas.

SELECT e.nombre AS empleado, j.nombre AS jefe
FROM empleados e
INNER JOIN empleados j ON e.jefe_id = j.id;
Analogía: Self-Join es como organizar un árbol genealógico: tienes una lista de personas, y para saber quién es hijo de quién, comparas la lista consigo misma.
