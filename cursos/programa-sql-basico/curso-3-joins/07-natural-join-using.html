NATURAL JOIN y USING

Módulo 7 Â· Joins

¿Qué aprenderás?

  • Usar NATURAL JOIN
  • Usar la cláusula USING
  • Entender sus diferencias con INNER JOIN
  • Saber cuándo usarlos con precaución

🧠 Intuición

NATURAL JOIN es como un INNER JOIN automático: SQL descubre por sí mismo las columnas con el mismo nombre y hace la coincidencia. Es cómodo pero peligroso.

USING es más explícito: le dices a SQL qué columna(s) usar para la coincidencia, pero sin escribir la tabla.

Ambos son atajos para escribir menos código, pero reducen la claridad.

📝 Sintaxis

SELECT * FROM tabla1 NATURAL JOIN tabla2;

SELECT * FROM tabla1 JOIN tabla2 USING (columna_comun);

NATURAL JOIN usa TODAS las columnas con el mismo nombre.

USING usa solo las columnas especificadas.

💻 Ejemplo

SELECT * FROM clientes NATURAL JOIN pedidos; — si ambas tienen 'id' como mismo significado, funciona.

SELECT * FROM clientes JOIN pedidos USING (cliente_id); — más seguro que NATURAL.

⚠️ Errores

NATURAL JOIN puede dar resultados incorrectos si hay columnas con el mismo nombre pero diferente significado.

No hay control sobre qué columnas usa NATURAL.

USING elimina la columna duplicada del resultado.

🔍 Dato

NATURAL JOIN es parte del estándar SQL pero muchos expertos lo evitan.

USING es más seguro que NATURAL JOIN.

Algunos SGBD no soportan NATURAL JOIN.

🎯 Clave

NATURAL JOIN = JOIN automático por columnas con mismo nombre.

USING = JOIN por columna(s) específica(s).

Ambos evitan escribir la condición ON.

Úsalos con precaución: prefiero ON explícito.

Ejemplo Paso a Paso

-- Paso 1: NATURAL JOIN (automático)
SELECT * FROM clientes NATURAL JOIN pedidos;
-- Asume que 'id' en clientes = 'id' en pedidos (peligroso si no es así)

-- Paso 2: USING (más seguro)
SELECT * FROM clientes JOIN pedidos USING (cliente_id);
-- Solo usa la columna 'cliente_id' para la coincidencia

-- Paso 3: Equivalente con ON
SELECT * FROM clientes c JOIN pedidos p ON c.cliente_id = p.cliente_id;

Concepto

NATURAL JOIN une automáticamente por columnas con el mismo nombre. USING especifica la(s) columna(s) de unión cuando tienen el mismo nombre.

SELECT * FROM clientes NATURAL JOIN pedidos;
SELECT * FROM clientes JOIN pedidos USING (cliente_id);
Analogía: NATURAL JOIN es como cuando emparejas personas con el mismo apellido automáticamente. USING es como decir "empareja por el campo 'email' que ambas tablas tienen".

Resumen del Módulo
