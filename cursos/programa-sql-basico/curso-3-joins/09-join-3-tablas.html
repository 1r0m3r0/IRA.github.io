JOIN de 3+ Tablas

Módulo 9 · Joins

Concepto

Puedes encadenar múltiples JOINs para combinar 3 o más tablas. Cada JOIN agrega otra tabla a la consulta.

SELECT c.nombre, p.total, pr.nombre
FROM clientes c
JOIN pedidos p ON c.id = p.cliente_id
JOIN productos pr ON p.producto_id = pr.id;
Analogía: Encadenar JOINs es como armar un rompecabezas de varias piezas: primero conectas las piezas A y B, luego agregas la pieza C, y así hasta tener la imagen completa.
