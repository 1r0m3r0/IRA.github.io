COUNT y Concepto de Agregación

Módulo 7 Â· Filtrado

¿Qué aprenderás?

  • Entender funciones de agregación
  • Usar COUNT para contar filas
  • Diferenciar COUNT(*) de COUNT(columna)
  • Aplicar COUNT con DISTINCT

🧠 Intuición

COUNT es como un contador automático. Si tienes 100 clientes, COUNT(*) te dice 'hay 100'.

COUNT(*) cuenta TODAS las filas. COUNT(columna) cuenta SOLO las filas donde esa columna NO es NULL.

COUNT(DISTINCT columna) cuenta los valores únicos no nulos.

📝 Sintaxis COUNT

SELECT COUNT(*) FROM tabla; — todas las filas.

SELECT COUNT(columna) FROM tabla; — filas no NULL.

SELECT COUNT(DISTINCT columna) FROM tabla; — valores únicos.

COUNT siempre devuelve un entero.

💻 Ejemplo

SELECT COUNT(*) AS total FROM clientes;

SELECT COUNT(email) AS con_email FROM clientes;

SELECT COUNT(DISTINCT ciudad) FROM clientes;

⚠️ Errores

COUNT(columna) NO cuenta NULL.

Usar COUNT(*) cuando necesitas COUNT(DISTINCT col).

COUNT es agregación: no puede usarse con columnas no-agregadas sin GROUP BY.

🔍 Dato

COUNT(*) es la función más optimizada en todos los SGBD.

COUNT(1) equivale a COUNT(*).

COUNT(NULL) siempre devuelve 0.

🎯 Clave

COUNT(*) cuenta todas las filas.

COUNT(col) cuenta filas NO NULL.

COUNT(DISTINCT col) cuenta valores únicos.

Ejemplo Paso a Paso

-- Paso 1: Contar todas las filas
SELECT COUNT(*) AS total FROM empleados;

-- Paso 2: Contar solo con email
SELECT COUNT(email) AS con_email FROM empleados;

-- Paso 3: Contar valores distintos
SELECT COUNT(DISTINCT departamento) AS deptos FROM empleados;

-- Paso 4: Combinar
SELECT COUNT(*) AS total, COUNT(email) AS con_email, COUNT(*) - COUNT(email) AS sin_email FROM clientes;

Concepto

COUNT() cuenta filas. COUNT(*) cuenta todas, COUNT(col) cuenta las no NULL.

SELECT COUNT(*) AS total FROM clientes;
SELECT COUNT(email) AS con_email FROM clientes;
Analogía: COUNT es como un contador de personas en un evento: "¿Cuántos invitados llegaron?" (COUNT(*)) vs "¿Cuántos dejaron su email?" (COUNT(columna)).
