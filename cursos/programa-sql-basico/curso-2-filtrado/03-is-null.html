IS NULL e IS NOT NULL

Módulo 3 · Filtrado

Concepto

NULL representa un valor ausente o desconocido. Se usa IS NULL o IS NOT NULL para comprobarlo (no = NULL).

SELECT * FROM clientes WHERE telefono IS NULL;
SELECT * FROM productos WHERE descripcion IS NOT NULL;
Analogía: NULL es como una casilla vacía en un formulario: no es "cero" ni "espacio en blanco", simplemente no se llenó. Preguntar "¿es igual a NULL?" no funciona; debes preguntar "¿está vacío?" (IS NULL).
