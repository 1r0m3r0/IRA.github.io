LIKE y Patrones de Búsqueda

Módulo 1 · Filtrado

Concepto

LIKE busca patrones en texto usando comodines: % (cualquier secuencia) y _ (un solo carácter).

SELECT * FROM clientes WHERE nombre LIKE 'A%'; -- Nombres que empiezan con A
SELECT * FROM clientes WHERE email LIKE '%@gmail.com';
Analogía: LIKE es como la búsqueda en tu celular: escribes "A%" y te muestra todos los contactos que empiezan con A. El % es el "comodín" que representa "lo que sea después".
