Funciones de Fecha

Módulo 5 · Filtrado

Concepto

SQL tiene funciones para trabajar con fechas: YEAR(), MONTH(), DAY(), DATE_DIFF(), NOW(), CURDATE().

SELECT YEAR(fecha_nacimiento) AS anio FROM clientes;
SELECT DATEDIFF(NOW(), fecha) AS dias_desde FROM pedidos;
Analogía: Las funciones de fecha son como un calendario programable: puedes preguntar "¿en qué año naciste?", "¿cuántos días han pasado?" o "¿qué fecha es hoy?".
