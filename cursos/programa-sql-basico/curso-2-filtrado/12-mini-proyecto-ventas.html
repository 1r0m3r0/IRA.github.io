Mini-Proyecto: Análisis de Ventas

Módulo 12 Â· Filtrado

¿Qué aprenderás?

  • Aplicar COUNT, SUM, AVG, GROUP BY y HAVING
  • Analizar datos de ventas reales
  • Combinar filtros con agregación
  • Interpretar resultados

🧠 Intuición

Este proyecto te pone en la piel de un analista de ventas. Tienes datos de productos, clientes y pedidos.

Usarás GROUP BY, HAVING, MIN, MAX, SUM y AVG para extraer información valiosa.

Estos análisis se usan en empresas para tomar decisiones: ¿qué se vende más? ¿qué clientes gastan más?

📝 Proyecto

Agrupar productos por categoría y contar.

Calcular precio promedio por categoría.

Encontrar clientes con más pedidos.

Identificar meses con mayores ventas.

💻 Consultas

SELECT categoria, COUNT(*) FROM productos GROUP BY categoria;

SELECT YEAR(fecha), SUM(total) FROM pedidos GROUP BY YEAR(fecha);

SELECT producto_id, COUNT(*) FROM detalle GROUP BY producto_id HAVING COUNT(*) > 5;

⚠️ Desafíos

No agrupar correctamente: SELECT sin GROUP BY con agregación da error.

Olvidar HAVING: WHERE no funciona con funciones de agregación.

No redondear: AVG da muchos decimales.

🔍 Dato

Los analistas junior pasan el 70% del tiempo haciendo GROUP BY.

Estas consultas se llaman OLAP.

Con GROUP BY respondes preguntas que en Excel tomarían horas.

🎯 Consejo

Empieza simple y añade complejidad.

Verifica resultados con conteos manuales.

Cada respuesta de negocio es una consulta SQL.

Ejemplo Paso a Paso

-- Ventas totales por mes
SELECT EXTRACT(YEAR FROM fecha) AS año, EXTRACT(MONTH FROM fecha) AS mes, SUM(total) AS ventas FROM pedidos GROUP BY año, mes ORDER BY año, mes;

-- Top 5 clientes por gasto
SELECT c.nombre, SUM(p.total) AS gasto FROM clientes c INNER JOIN pedidos p ON c.id=p.cliente_id GROUP BY c.nombre ORDER BY gasto DESC LIMIT 5;

El Desafío Final

Aplica funciones de agregación, GROUP BY y HAVING para analizar datos de ventas semanales.

Práctica real: Este análisis simula lo que harías como analista de datos: encontrar productos estrella, días pico y rendimiento por categoría.
