Concepto

Funciones matemáticas: ROUND(), ABS(), CEIL(), FLOOR(), POWER(), SQRT().

SELECT ROUND(precio, 2) FROM productos;
SELECT ABS(saldo) FROM cuentas;
SELECT CEIL(precio) AS precio_redondeado FROM productos;
Analogía: Son como las funciones de una calculadora científica: redondear (ROUND), valor absoluto (ABS), techo (CEIL), piso (FLOOR), potencia (POWER) y raíz (SQRT).
