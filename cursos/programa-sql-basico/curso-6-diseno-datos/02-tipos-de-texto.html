📝 Tipos de Texto

CHAR, VARCHAR y TEXT — el tamaño importa

💡 Piénsalo así: CHAR es como una placa de automóvil — siempre del mismo tamaño, aunque el texto sea más corto (se rellena con espacios). VARCHAR es como una nota adhesiva — usa solo el espacio que necesita, hasta un máximo. TEXT es como un cuaderno completo — sin límite predefinido. CHAR(10) siempre ocupa 10 caracteres; VARCHAR(10) ocupa solo lo que escribas (máximo 10).

Regla de oro: VARCHAR para la mayoría de textos cortos/medios, TEXT para descripciones largas, CHAR solo para códigos de longitud fija (CURP, ISBN).
