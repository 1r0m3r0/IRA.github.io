Verdadero, falso y... el misterioso NULL

💡 Piénsalo así: BOOLEAN es como un interruptor de luz: puede estar encendido (TRUE), apagado (FALSE), o... ¿sin electricidad? (NULL = "no lo sé"). En SQL, el booleano tiene tres estados: TRUE, FALSE y NULL (desconocido). NULL en lógica booleana no es "falso", es "no sé". TRUE AND NULL = NULL (porque si una parte es desconocida, el resultado es desconocido).

PostgreSQL acepta 'true'/'false', 't'/'f', '1'/'0', TRUE/FALSE, 'yes'/'no', 'on'/'off'. Muy flexible.
