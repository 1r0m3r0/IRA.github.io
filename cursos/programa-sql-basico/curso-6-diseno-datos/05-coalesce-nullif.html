🔄 COALESCE / NULLIF

Domina los valores NULL como un profesional

💡 Piénsalo así: COALESCE es como tener un plan B, C y D: "Si no encuentras leche, usa agua; si no hay agua, usa jugo". Devuelve el primer valor NO NULL de la lista. NULLIF es lo contrario: "Si el valor es igual a X, entonces devuelve NULL". Útil para evitar divisiones por cero o convertir valores especiales en NULL.

COALESCE(nombre, 'Sin nombre') → si nombre es NULL, devuelve 'Sin nombre'
NULLIF(valor, 0) → si valor es 0, devuelve NULL
