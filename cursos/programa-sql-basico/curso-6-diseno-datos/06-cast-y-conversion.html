🔄 CAST y Conversión

Transforma datos de un tipo a otro — el traductor universal de SQL

💡 Piénsalo así: CAST es como un traductor simultáneo: toma un dato en "idioma" TEXT y lo traduce a "idioma" INTEGER, o viceversa. Hay dos formas de hacerlo: CAST(valor AS tipo) (forma estándar SQL) y la notación con :: (valor::tipo, específica de PostgreSQL). La notación :: es más rápida de escribir, pero CAST es más portable entre motores de BD.

SELECT '123'::INTEGER; → convierte texto a número
SELECT CAST(precio AS VARCHAR); → convierte número a texto
SELECT '2024-01-15'::DATE; → convierte texto a fecha
