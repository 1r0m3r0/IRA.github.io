📅 Tipos Fecha / Hora

DATE, TIME, TIMESTAMP ” el tiempo en SQL

💡 Piénsalo así: DATE es como una hoja de calendario (solo la fecha). TIME es como un reloj de pared (solo la hora). TIMESTAMP es como una foto con fecha y hora en la esquina inferior (ambos). TIMESTAMPTZ añade la zona horaria. INTERVAL es como un cronómetro ” mide la DURACIÃ“N entre dos momentos. PostgreSQL tiene las funciones de fecha más potentes de todos los motores SQL.

Ejemplo: '2024-12-25'::DATE, '15:30:00'::TIME, '2024-12-25 15:30:00'::TIMESTAMP

¿Qué aprenderás?

  • Conocer tipos de fecha/hora en SQL
  • Usar DATE, TIME, TIMESTAMP
  • Trabajar con INTERVAL
  • Elegir el tipo de fecha adecuado

🧠 Intuición

DATE guarda solo la fecha (año-mes-día). TIME guarda solo la hora. TIMESTAMP guarda ambos. INTERVAL guarda periodos de tiempo.

Elegir el tipo correcto evita conversiones y errores. Si solo necesitas la fecha, no uses TIMESTAMP.

PostgreSQL tiene TIMESTAMP con y sin zona horaria (TIMESTAMPTZ).

📝 Tipos de Fecha/Hora

DATE: fecha (2024-01-15).

TIME: hora (14:30:00).

TIMESTAMP: fecha + hora (2024-01-15 14:30:00).

TIMESTAMPTZ: con zona horaria.

INTERVAL: periodo (1 year 2 months).

💻 Ejemplo

fecha_nacimiento DATE, hora_entrada TIME, creado_en TIMESTAMP DEFAULT NOW(), duracion INTERVAL '2 hours'

⚠️ Errores

Guardar hora en DATE: se pierde.

No considerar zona horaria: TIMESTAMP sin TZ puede confundir.

Formato incorrecto: '2024/01/15' vs '2024-01-15'.

🔍 Dato

PostgreSQL almacena TIMESTAMP en 8 bytes.

CURRENT_DATE, CURRENT_TIME, NOW() son funciones útiles.

AGE() calcula la edad entre dos fechas como INTERVAL.

🎯 Clave

DATE = solo fecha.

TIME = solo hora.

TIMESTAMP = fecha + hora.

TIMESTAMPTZ = con zona horaria.

INTERVAL = periodo de tiempo.

Ejemplo Paso a Paso

-- Paso 1: Tabla con tipos de fecha/hora
CREATE TABLE eventos (
id SERIAL PRIMARY KEY,
fecha_evento DATE NOT NULL, -- solo fecha
hora_inicio TIME, -- solo hora
creado_en TIMESTAMP DEFAULT NOW(), -- fecha + hora
duracion INTERVAL -- periodo:'2 hours'
);

-- INSERT ejemplo
INSERT INTO eventos (fecha_evento, hora_inicio, duracion)
VALUES ('2024-12-25', '20:00:00', '3 hours');
