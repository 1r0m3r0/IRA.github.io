PyTorch

Simulador de tensores: crea tensores, GPU simulado, nn.Module, Autograd demo.

Como una hoja de cálculo mágica: Los tensores son como matrices multidimensionales. PyTorch es como tener una hoja de cálculo que no solo guarda números, sino que recuerda cómo se calcularon (Autograd = "auto-gradiente"). Es como si cada celda supiera su historial de operaciones. Perfecto para entrenar redes con backpropagation.
