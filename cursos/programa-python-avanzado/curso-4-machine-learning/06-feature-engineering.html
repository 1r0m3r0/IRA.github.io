Feature Engineering

Juego de features: encoding, scaling, polynomial, binning. Score de mejora.

Como preparar ingredientes para cocinar: Las features son tus ingredientes. Feature engineering es cortar, marinar, mezclar y sazonar para que el modelo "chef" pueda hacer el mejor platillo. Escalar es como cortar todo en trozos del mismo tamaño. One-hot encoding es como separar ingredientes en distintos recipientes. Las features polinomiales son como hacer mezclas creativas.
