Free-threaded Python (sin GIL)

PEP 703/779: CPU-bound con threads en modo con/sin GIL

Sin GIL PEP 703 Performance
Piensa en una autopista de peaje: El GIL era como tener un único peaje para 8 carriles. Free-threaded Python (PEP 703) es como quitar el peaje: todos los autos pasan simultáneamente. Para tareas CPU-bound (como calcular pi), el cuello de botella desaparece. PEP 779 propone hacer esto por defecto en Python 3.15.
