Trio

Structured concurrency, nursery, cancellation scopes vs asyncio

Nursery Cancellation Structured
Piensa en un equipo de obra: asyncio es como tener trabajadores independientes: cada uno sabe qué hacer pero es fácil perder el control. Trio introduce "structured concurrency": un capataz (nursery) supervisa un grupo de trabajo. Si un trabajador falla, el capataz cancela a todos y limpia. Así nunca dejas tareas huérfanas.

asyncio

async def main():
  t1 = create_task(f())
  t2 = create_task(g())
  await t1
  await t2
# Si t2 falla, t1 sigue

Trio

async def main():
  async with open_nursery() as n:
    n.start_soon(f)
    n.start_soon(g)
# Si g falla, f se cancela
