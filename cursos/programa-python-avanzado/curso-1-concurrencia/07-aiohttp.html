aiohttp

Cliente HTTP asíncrono: requests concurrentes con session pool

Async HTTP Session Pool Concurrente
Piensa en un cartero: requests síncrono es como enviar 10 cartas, esperar la respuesta de una antes de enviar la siguiente. aiohttp es como tener 10 carteros que entregan y recogen simultáneamente. El session pool es como tener una flota de carteros lista para trabajar.
