Multiprocessing y Pool

Threading vs Multiprocessing: CPU-bound vs I/O-bound

Pool.map Shared Memory Queue IPC
Piensa en una oficina: Threading es como tener 5 empleados en una sola oficina compartiendo una computadora (GIL). Multiprocessing es darle a cada empleado su propia computadora en su propia oficina. Para tareas CPU-intensivas (como renderizar video), cada quien necesita su máquina. Para I/O (como descargar archivos), compartir la computadora funciona bien.
