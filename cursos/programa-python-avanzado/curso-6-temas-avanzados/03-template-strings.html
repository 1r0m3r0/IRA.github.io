Template Strings (PEP 750 - Python 3.14)

Constructor t-strings: templates personalizados con interpolación.

Como una plantilla de carta personalizable: Las f-strings son como tarjetas pre-hechas con espacios en blanco. Los t-strings (template strings) de Python 3.14 son como marcadores de posición inteligentes: no solo reemplazan texto, sino que pueden ejecutar validación, escape de HTML, formateo de fechas y más. Es como tener un asistente que sabe exactamente cómo rellenar cada campo.
