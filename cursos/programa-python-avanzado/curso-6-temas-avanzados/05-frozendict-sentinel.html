Python 3.15: frozendict y sentinel

Juego de features: frozendict inmutable (PEP 814), sentinel (PEP 661). Quiz.

Cosas que no deberían cambiar: frozendict es como un contrato firmado: una vez escrito, nadie puede modificarlo. Perfecto para configuraciones globales. sentinel es como una "marca de agua" especial que indica "no se proporcionó valor", distinto de None (que podría ser un valor válido). Antes la gente usaba object() para esto, ahora hay un sentinel oficial.
