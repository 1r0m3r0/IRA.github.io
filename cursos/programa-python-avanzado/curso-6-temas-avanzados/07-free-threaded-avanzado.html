Free-threaded Python Avanzado

Benchmarks CPU-bound con/sin GIL. Numba parallel. PEP 779.

Como quitarle los grilletes a un corredor: El GIL (Global Interpreter Lock) es como un grillete que solo permite que un thread corra a la vez. Free-threaded Python (PEP 779, Python 3.13+) es como quitarle los grilletes: todos los threads pueden correr en paralelo real. Para tareas CPU-bound (cálculos numéricos, procesamiento de imágenes), la diferencia es enorme.
