WebAssembly y Pyodide

Simulador Python en navegador: Pyodide, wasm-pack, Python en WebAssembly.

Como llevar un coche a una isla: WebAssembly (WASM) es como un ferry que puede transportar cualquier vehículo a un navegador web. Pyodide es un coche Python que viaja en ese ferry. Una vez dentro del navegador, Python puede hacer de todo: manipular el DOM, procesar datos, incluso usar numpy y matplotlib, todo sin servidor. Es como tener Python corriendo en una isla remota (el navegador del usuario).

Simulador Python en el Navegador (Pyodide)

Escribe código Python y "ejecútalo" en un navegador simulado con Pyodide/WASM.

import numpy as np\n\ndef fibonacci(n):\n a, b = 0, 1\n for _ in range(n):\n a, b = b, a + b\n return a\n\nprint(fibonacci(10))
