CLI Profesionales (Typer, Rich, Click)

Constructor CLI: Typer args/options/subcomandos. Rich tablas/progress bars.

Como un asistente de voz para tu terminal: Crear una CLI con Typer es como enseñarle a tu computadora comandos de voz personalizados. "cli.py procesar --input datos.csv --output resultado.json" es como decir "asistente, procesa este archivo y guarda el resultado allí". Rich es el que hace que la respuesta se vea bonita: tablas, barras de progreso, colores. Click es la versión clásica y robusta.

Constructor de CLI Interactivo

Configura un comando CLI con Typer y ejecuta el comando simulado en la terminal.




$ python app.py --help
