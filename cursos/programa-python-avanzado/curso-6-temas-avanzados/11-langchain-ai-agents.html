LangChain + AI Agents

Simulador AI agent: prompt → LLM → tools → memory. LangChain Agent.

Como un asistente personal con superpoderes: LangChain es como tener un mayordomo que puede usar herramientas. Le dices "consigue el clima y agéndame una reunión", y él: 1) busca el clima (tool: weather API), 2) revisa tu calendario (tool: calendar), 3) agenda la reunión (tool: create event). Todo mientras recuerda la conversación (memory). Los AI Agents son mayordomos que deciden qué herramienta usar y en qué orden.
