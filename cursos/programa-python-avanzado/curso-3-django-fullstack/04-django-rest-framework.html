Django REST Framework

Serializers, ViewSets, Routers y browsable API

Serializers ViewSets Routers
Piensa en una empresa de logística: Serializers son como empaquetadores: convierten objetos Python (cajas) a JSON (paquetes) y viceversa. ViewSets son como los departamentos: UsersViewSet, ProductsViewSet. Routers son las rutas de entrega: conectan direcciones URL con el departamento correcto.

API Builder

Construye una API REST para Books usando DRF.

Serializer

class BookSerializer(serializers.ModelSerializer):
  class Meta:
    model = Book
    fields = ['id','title','author']

ViewSet + Router

class BookViewSet(ModelViewSet):
  queryset = Book.objects.all()
  serializer_class = BookSerializer

router.register('books', BookViewSet)
