Modelos, Migraciones y Admin

Define modelos Author/Book con fields, relaciones y admin personalizado

Fields Relaciones Admin
Piensa en una biblioteca: Los modelos son como las fichas del catálogo: Author (autor), Book (libro). Cada ficha tiene campos (título, fecha, ISBN). Las migraciones son como actualizar el catálogo cuando llegan libros nuevos. El admin es el bibliotecario que puede ver y modificar las fichas.
