Django MTV

Model-Template-View flow y configuracion de proyecto

Model Template View
Piensa en una imprenta: El Model es el contenido del libro (datos), la View decide qué páginas se imprimen (lógica), y el Template es el diseño de cada página (presentación). El flujo MTV: URL → View obtiene datos del Model → View pasa datos al Template → Template genera HTML.
