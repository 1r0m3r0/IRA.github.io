Testing en Django

TestCase, Client, APITestCase, factory_boy, coverage

TestCase APITestCase factory_boy
Piensa en un inspector de calidad: Los tests son como inspectores que verifican cada pieza antes de enviarla. TestCase es el inspector general. Client es el que simula a un usuario navegando. APITestCase es el que prueba la API. factory_boy es una fábrica que crea datos de prueba rápidamente.
