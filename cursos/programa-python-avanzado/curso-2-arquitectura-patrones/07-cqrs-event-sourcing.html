CQRS y Event Sourcing

Commands vs Queries, Event Store y reconstrucción de estado

Commands Queries Event Store
Piensa en un banco: CQRS separa la escritura (commands: depositar, retirar) de la lectura (queries: ver saldo). Event Sourcing es como guardar el libro de transacciones completo en vez de solo el saldo actual. Para saber el saldo, replay all events. Nunca pierdes la historia.
