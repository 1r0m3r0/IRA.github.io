Microservicios

Divide un monolito en servicios independientes y define APIs

Servicios APIs Sincronización
Piensa en un restaurante: Un monolito sería un solo chef que cocina, limpia y atiende mesas. Microservicios son: cocina (servicio A), barra (servicio B), caja (servicio C). Cada uno tiene su API (menú). Si la cocina falla, la barra sigue funcionando. Comunicación por pedidos (eventos).
