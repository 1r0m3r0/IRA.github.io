Domain-Driven Design

Entities, Value Objects, Aggregates, Repositories

Entity Value Object Aggregate
Piensa en un pedido de compra: El Pedido es un Entity (tiene identidad propia, cambia de estado). La Dirección es un Value Object (si cambia, es otra dirección). El Pedido + sus Líneas forman un Aggregate (todo el grupo se valida junto). El repositorio es el archivo donde guardamos los pedidos.
