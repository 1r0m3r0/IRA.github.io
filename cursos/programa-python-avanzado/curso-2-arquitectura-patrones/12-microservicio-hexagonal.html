Proyecto: Microservicio Hexagonal

Microservicio de usuarios con Clean Architecture completa

Domain Application Infrastructure
Piensa en un juego de bloques: La arquitectura hexagonal es como un bloque central (domain) que no depende de nada. Alrededor se conectan diferentes piezas (adapters): una base de datos, una API REST, un bus de eventos. Puedes cambiar cualquier pieza externa sin tocar el bloque central. ¡Eso es un microservicio hexagonal!
