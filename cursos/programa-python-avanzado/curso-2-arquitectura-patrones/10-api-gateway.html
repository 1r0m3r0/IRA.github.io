API Gateway

Rutas, rate limiting, auth, aggregation y BFF

Routing Rate Limit Auth
Piensa en la recepción de un hotel: El API Gateway es como la recepción: todos los huéspedes (clientes) llegan ahí. La recepción verifica identidad (auth), limita cuántos pueden pasar (rate limiting), y dirige a cada quien a su habitación (routing). BFF (Backend For Frontend) es como tener recepciones especializadas: una para huéspedes VIP, otra para eventos.
