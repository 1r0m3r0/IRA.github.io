Serverless

Constructor serverless: Lambda + API Gateway + DynamoDB. Serverless vs tradicional.

Como pedir un taxi vs comprar un coche: Serverless es como Uber: pagas solo cuando viajas (ejecutas código), no te preocupas por mantenimiento (servidores), y siempre hay disponibilidad. La arquitectura tradicional (servidores) es como comprar un coche: pagas siempre (haya o no viajes), pero tienes control total. Lambda (viaje), API Gateway (la app del taxi), DynamoDB (el GPS).
