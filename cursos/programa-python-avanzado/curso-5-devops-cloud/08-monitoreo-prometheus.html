Monitoreo (Prometheus, Grafana)

Dashboard de métricas: Prometheus endpoint, Grafana dashboard, alertas.

Como el panel de control de un avión: Prometheus es el sistema que recolecta datos de todos los sensores (altitud, velocidad, combustible) en tiempo real. Grafana es el panel de instrumentos que muestra esos datos en gráficas bonitas y entendibles. Las alertas son como las alarmas que suenan cuando algo va mal (presión baja, altitud crítica).
