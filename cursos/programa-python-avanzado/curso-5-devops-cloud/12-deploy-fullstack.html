Despliega app completa: GitHub → CI/CD → Docker → AWS ECS/K8s + monitoreo.

Como lanzar un cohete al espacio: Desplegar una app full-stack es como lanzar un cohete: necesitas una plataforma de lanzamiento (GitHub), combustible (código), controles de misión (CI/CD que verifica todo), el cohete mismo (Docker), órbita (AWS ECS/K8s) y monitoreo (Prometheus/Grafana para saber si el cohete está bien). Si algo falla, abortas el lanzamiento.
