Producción FastAPI

Dashboard de producción: Uvicorn workers, Gunicorn, Nginx, SSL, supervisor.

Como abrir un restaurante: FastAPI es el chef que prepara los platos rápido. Uvicorn es el mesero que lleva los platos a la mesa. Gunicorn es el gerente que coordina varios meseros (workers). Nginx es el anfitrión en la puerta que decide quién entra (proxy inverso). SSL son las puertas con cerradura de seguridad.
