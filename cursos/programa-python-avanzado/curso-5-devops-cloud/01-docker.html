Docker para Python

Constructor de Dockerfile: build, run, layers, .dockerignore, multi-stage. Quiz.

Como empacar una maleta para un viaje: Docker es como una maleta perfectamente organizada que contiene todo lo que necesitas: código (ropa), dependencias (artículos de aseo), sistema operativo (la maleta misma). El Dockerfile es la lista de empaque. Las layers son capas de ropa: la base va abajo (OS), luego las herramientas (Python), luego tu código (camiseta favorita) arriba.
