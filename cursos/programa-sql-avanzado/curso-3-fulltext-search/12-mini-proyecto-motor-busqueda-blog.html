¿Qué aprenderás?

  • A crear tsvectors con to_tsvector para indexar texto en PostgreSQL
  • A construir tsqueries con operadores &, |, ! y <->
  • A usar el operador @@ para hacer búsqueda de texto completo
  • A optimizar búsquedas con índices GIN y GiST
  • A ordenar resultados por relevancia con ts_rank y ts_rank_cd

Tokenización

El proceso de dividir el texto en tokens individuales (palabras). PostgreSQL elimina signos de puntuación y normaliza mayúsculas/minúsculas antes de crear el tsvector.

SELECT to_tsvector('spanish', 'Hola Mundo!');
⚠ Siempre especifica el idioma para una mejor tokenización

Lexemas

Los lexemas son las unidades básicas de búsqueda. PostgreSQL reduce cada palabra a su raíz (lematización) para que 'corriendo', 'correr' y 'correré' coincidan.

SELECT to_tsvector('spanish', 'corriendo correr correré');
⚠ El diccionario de español maneja conjugaciones verbales

Stop Words

Palabras comunes (el, la, de, y, en) que se eliminan automáticamente porque no aportan valor semántico a la búsqueda. PostgreSQL tiene listas por idioma.

SELECT to_tsvector('spanish', 'el gato y el perro');
⚠ Puedes crear tu propia lista de stop words personalizada

Posiciones

tsvector guarda la posición de cada lexema en el documento original. Esto permite búsquedas por proximidad y frases exactas con el operador <->.

SELECT tsvector('gato:1 perro:2 casa:3');
⚠ Las posiciones permiten búsqueda de frases exactas

Configuración de Idioma

PostgreSQL soporta múltiples idiomas para FTS. 'spanish', 'english', 'french', etc. Cada uno tiene su propio diccionario de stemming y stop words.

SELECT to_tsvector('english', 'running dogs');
⚠ Usa el idioma correcto para mejores resultados

to_tsvector vs tsvector

to_tsvector() aplica el diccionario completo (tokenización + stemming + stop words). El cast ::tsvector solo parsea el formato ya procesado.

SELECT to_tsvector('spanish', 'corriendo') VS 'corriendo'::tsvector;
⚠ Siempre prefiere to_tsvector() para texto nuevo

Ejemplo paso a paso

1

Crea una tabla de ejemplo con contenido textual para buscar

CREATE TABLE articulos ( id SERIAL PRIMARY KEY, titulo TEXT, contenido TEXT );
2

Inserta algunos documentos de ejemplo con diferentes temáticas

INSERT INTO articulos (titulo, contenido) VALUES ('PostgreSQL Avanzado', 'Guía completa sobre optimización de consultas en PostgreSQL'), ('Búsqueda de Texto', 'Cómo implementar full-text search con tsvector y tsquery');
3

Agrega una columna tsvector generada automáticamente para búsqueda

ALTER TABLE articulos ADD COLUMN contenido_tsv TSVECTOR GENERATED ALWAYS AS (to_tsvector('spanish', titulo || ' ' || contenido)) STORED;
4

Crea un índice GIN para acelerar las búsquedas de texto completo

CREATE INDEX idx_fts_articulos ON articulos USING GIN (contenido_tsv);
5

Ejecuta una búsqueda FTS y observa la velocidad con EXPLAIN ANALYZE

EXPLAIN ANALYZE SELECT * FROM articulos WHERE contenido_tsv @@ to_tsquery('spanish', 'postgres & optimización');
