🔤 unaccent

Elimina acentos y diacríticos para búsquedas sin distinción

💡 Piénsalo así: unaccent es como un traductor que quita los sombreros de las letras. "Canción", "cancion", "cançion" todas se convierten en "cancion". Esto permite que si buscas "cancion", encuentres documentos que tengan "canción", "canciones", etc. Es esencial para el español donde los acentos cambian el significado pero no deberían romper la búsqueda.
🔴 Con acentos
Canción de amor para la educación musical
🟢 Sin acentos (unaccent)
Cancion de amor para la educacion musical
á→a é→e í→i ó→o ú→u ü→u ñ→n
💬 unaccent() se usa con FTS: CREATE TEXT SEARCH CONFIGURATION es_fts (COPY = spanish); ALTER TEXT SEARCH CONFIGURATION es_fts ALTER MAPPING FOR hword, hword_part, word WITH unaccent, spanish_stem;
