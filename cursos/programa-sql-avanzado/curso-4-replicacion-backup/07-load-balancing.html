⚖️ Load Balancing

Distribuye lecturas entre réplicas con HAProxy, pgpool-II y balanceo de conexiones.

🎯 Piénsalo así: El load balancing es como las cajas de un supermercado. En lugar de tener una sola caja donde todos hacen fila (un solo servidor), abres varias cajas (réplicas) y un recepcionista (balanceador) dirige a cada cliente a la caja menos ocupada. Las cajas pueden leer el precio de los productos, pero solo la caja principal puede aceptar devoluciones (escrituras).
