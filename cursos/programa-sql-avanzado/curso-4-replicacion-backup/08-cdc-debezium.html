⚡ CDC con Debezium

Captura de cambios en tiempo real: integra PostgreSQL con Kafka mediante Debezium para event sourcing.

🎯 Piénsalo así: CDC (Change Data Capture) con Debezium es como un periodista incrustado en la sala de redacción. Cada vez que ocurre un cambio (noticia), el periodista la escribe en un teletipo (Kafka) para que todos los periódicos, radios y TVs (consumidores) se enteren en tiempo real. El periodista no interfiere con el trabajo de la sala, solo observa y reporta.

💬 Debezium es una plataforma de CDC distribuida que se conecta a PostgreSQL mediante logical replication slots. Cada cambio en las tablas seleccionadas genera un evento estructurado (avro o JSON) que se publica en Apache Kafka para que otros sistemas lo consuman.
