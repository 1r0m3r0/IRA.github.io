🕰️ PITR — Point-in-Time Recovery

Recuperación a un instante exacto: restaura con archive WAL, timelines y recovery targets.

🎯 Piénsalo así: PITR es como tener una máquina del tiempo para tu base de datos. Así como puedes rebobinar una película a cualquier escena, PITR te permite restaurar tu base de datos a cualquier segundo del pasado. Si alguien borró datos a las 14:32, puedes restaurar la BD justo antes de ese momento, como si nada hubiera pasado.

🕰️ Línea de Tiempo PITR: Restaura al Segundo Exacto

⏱️ Línea de tiempo: Normal
📅 Eventos hoy:
• 08:00 — Backup completo (LSN 0/1A000000)
• 10:15 — Transacción normal

• 14:31 — Último estado válido
💡 Interactúa con los controles de arriba
💬 PITR permite restaurar una base de datos a cualquier punto en el tiempo usando un backup base + el archive WAL. Configurando archive_mode, archive_command y recovery_target_time en recovery.conf, puedes recuperar datos al segundo exacto antes de un desastre.
