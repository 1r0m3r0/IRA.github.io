💾 pg_basebackup

Crea réplicas y backups físicos con pg_basebackup. El estándar para provisioning de servidores standby.

🎯 Piénsalo así: pg_basebackup es como hacer una fotocopia certificada de un libro completo mientras el autor sigue escribiendo. El bibliotecario (PostgreSQL) te permite copiar página por página mientras registra los cambios nuevos en una lista (WAL). Al terminar, aplicas los cambios pendientes y tienes una copia exacta al momento exacto.

💾 Constructor de Comando pg_basebackup

pg_basebackup -h localhost -D /backup/standby -X stream --progress
💡 Interactúa con los controles de arriba
💬 pg_basebackup es la herramienta oficial de PostgreSQL para crear backups físicos del cluster. Copia todos los archivos de datos más el WAL necesario para que el backup sea consistente. Es el método recomendado para crear servidores standby y para backups base en estrategias de PITR.
