🏆 Mini-Proyecto: Seguridad Corporativa

Diseña e implementa una estrategia completa de seguridad: roles, RLS, SSL, TDE, auditoría y pentest.

🎯 Piénsalo así: Este proyecto es como diseñar la seguridad de una fortaleza medieval. Necesitas muros (SSL para el perímetro), guardias en cada puerta (roles y permisos para acceso), puertas con llave por habitación (RLS a nivel fila), un cofre del tesoro blindado (TDE para datos sensibles), un vigilante que registra todo (pgaudit) y un entrenamiento contra engaños (SQL injection prevention). Todo debe funcionar en conjunto.
