👤 CREATE ROLE / USER

Crea roles y usuarios con herencia, LOGIN, CREATEDB, REPLICATION y más atributos.

🎯 Piénsalo así: CREATE ROLE es como crear credenciales de acceso para un edificio corporativo. Un rol puede ser una persona (con LOGIN) o un puesto (sin LOGIN, pero con permisos que se heredan). CREATEDB es como tener llave del sótano de archivos, REPLICATION es acceso a la sala de servidores. Los roles se organizan como un organigrama: roles de grupo contienen roles de empleados.

👤 Constructor de Roles y Usuarios

-- Genera un rol con las opciones seleccionadas
CREATE ROLE analista WITH LOGIN CREATEDB INHERIT;
💡 Interactúa con los controles de arriba
💬 CREATE ROLE es la base de la seguridad en PostgreSQL. Los roles con LOGIN son usuarios. Los roles sin LOGIN son grupos. La herencia permite que un rol miembro herede permisos del rol padre. Atributos como SUPERUSER, CREATEDB y REPLICATION conceden poderes especiales.
