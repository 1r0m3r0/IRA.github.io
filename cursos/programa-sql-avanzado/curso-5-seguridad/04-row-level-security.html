🛡️ Row-Level Security (RLS)

Políticas de acceso a nivel fila: CREATE POLICY, USING, WITH CHECK, FOR ALL.

🎯 Piénsalo así: RLS es como un portero en cada fila de una tabla. Sin RLS, si tienes acceso a la tabla ves todas las filas. Con RLS, el portero revisa tu identificación en cada fila y solo te deja ver las que te corresponden. Un empleado de RH solo ve sus propias evaluaciones, no las de todos. Es como un SELECT con WHERE automático que PostgreSQL añade a cada consulta.
