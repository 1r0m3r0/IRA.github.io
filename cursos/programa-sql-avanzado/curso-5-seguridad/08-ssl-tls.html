🔐 SSL / TLS

Cifra conexiones con certificados: ca.crt, server.crt, server.key, sslmode=verify-full.

🎯 Piénsalo así: SSL/TLS en PostgreSQL es como enviar una carta certificada con sello de cera. La carta (datos) viaja dentro de un sobre sellado que solo el destinatario puede abrir. El certificado (server.crt) es como el sello real que garantiza que el destinatario es quien dice ser. sslmode=verify-full es como verificar el sello con una lupa antes de entregar la carta.

🔐 Configurador SSL/TLS

🔓 SSL: DESHABILITADO
postgresql.conf: ssl = off
💡 Interactúa con los controles
💬 SSL/TLS cifra todo el tráfico entre cliente y servidor PostgreSQL. Requiere certificados (server.crt, server.key) y configurar postgresql.conf (ssl=on). sslmode controla la verificación: require cifra pero no verifica el servidor, verify-full verifica el nombre del host contra el certificado.
