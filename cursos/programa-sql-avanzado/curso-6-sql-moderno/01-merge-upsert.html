🔀 MERGE / UPSERT

INSERT ON CONFLICT y MERGE (SQL:2023). Sincroniza tablas con lógica upsert y merge condicional.

🎯 Piénsalo así: MERGE / UPSERT es como actualizar tu agenda de contactos. Cuando alguien te da una tarjeta nueva, revisas si ya existe: si sí, actualizas los datos; si no, agregas un nuevo contacto. PostgreSQL hace esto automáticamente con INSERT ON CONFLICT DO UPDATE. MERGE (SQL:2023) va más allá: permite personalizar qué hacer cuando hay coincidencia Y cuando no.

🔀 Simulador MERGE / UPSERT

📊 Tabla: inventario (producto, stock)

🟢 INSERT ON CONFLICT (id) DO UPDATE SET stock = stock + EXCLUDED.stock
💡 Interactúa con los controles
💬 INSERT ON CONFLICT (PostgreSQL 9.5+) permite upsert: intenta insertar, si hay conflicto (PK/unique) hace UPDATE. MERGE (SQL:2023, PostgreSQL 15+) es más potente: permite WHEN MATCHED / WHEN NOT MATCHED con condiciones personalizadas. Ideal para sincronización de datos y ETL.
