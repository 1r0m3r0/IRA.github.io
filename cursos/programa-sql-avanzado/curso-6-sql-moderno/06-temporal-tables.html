⏳ Temporal Tables (System-Versioned)

Tablas con versionado automático de datos. Consulta el estado histórico en cualquier punto del tiempo.

🎯 Piénsalo así: Las tablas temporales (system-versioned) son como el historial de versiones de Google Docs. Cada vez que alguien edita un documento, Google guarda una versión anterior. Puedes volver a cualquier versión anterior y ver exactamente lo que había. Las temporal tables hacen esto con tus datos: cada UPDATE o DELETE guarda automáticamente el registro anterior con marcas de tiempo.

⏳ Simulador de Tabla Temporal (FOR SYSTEM_TIME)

📊 Simulador de tablas con versionado automático
💡 Interactúa con los controles
💬 System-versioned temporal tables (SQL:2011, implementado en MariaDB, SQL Server, DB2, PostgreSQL vía extensiones) guardan automáticamente todas las versiones de cada fila. FOR SYSTEM_TIME AS OF permite consultar el estado en cualquier momento. La tabla histórica es mantenida automáticamente por el motor.
