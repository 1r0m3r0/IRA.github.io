📊 GROUPING SETS / CUBE / ROLLUP

Agrupaciones multidimensionales en una sola consulta. Genera subtotales, totales y diagonales de datos.

🎯 Piénsalo así: GROUPING SETS es como un cubo Rubik de datos. ROLLUP (acumulativo) es como un informe financiero: subtotal por mes → trimestre → año. CUBE genera todas las combinaciones posibles: es como ver un cubo de datos desde todos los ángulos. GROUPING SETS te permite elegir exactamente qué combinaciones quieres.

📊 Generador de Agrupaciones Multidimensionales

📊 Datos de ventas por región, producto y mes
💡 Interactúa con los controles
💬 ROLLUP genera subtotales jerárquicos (región → producto → total). CUBE genera todas las combinaciones posibles (2^n grupos). GROUPING SETS permite seleccionar combinaciones específicas. GROUPING() identifica filas de subtotal vs detalle.
