🕸️ SQL/PGQ y Grafos en SQL

Property Graph Queries (SQL:2023) y modelado de grafos con tablas relacionales. CTE recursivas y AGE.

🎯 Piénsalo así: Un grafo en SQL es como el mapa del metro. Las estaciones son los nodos (vértices), y las líneas que conectan estaciones son las aristas (edges). SQL/PGQ (SQL:2023) permite consultar estos grafos con sintaxis especial: MATCH (nodo) -[relacion]-> (otro). En PostgreSQL, esto se hace con CTE RECURSIVAS (recorridos jerárquicos) o con Apache AGE (extensión de grafos).

🕸️ Explorador de Grafos Relacionales

🤖 Base de grafos: nodos (personas) y aristas (sigue_a)
💡 Interactúa con los controles
💬 SQL:2023 introduce SQL/PGQ (Property Graph Queries) con sintaxis MATCH. PostgreSQL lo implementa con CTE recursivas y Apache AGE (fork de AgensGraph). Los grafos se modelan con tablas de nodos y aristas. Útil para redes sociales, recomendaciones, detección de fraudes y rutas.
