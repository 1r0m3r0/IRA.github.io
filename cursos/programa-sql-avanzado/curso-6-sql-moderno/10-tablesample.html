🎲 TABLESAMPLE

Muestreo estadístico de tablas. SYSTEM y BERNOULLI para obtener subconjuntos aleatorios representativos.

🎯 Piénsalo así: TABLESAMPLE es como probar la sopa con una cuchara. No necesitas comerte toda la olla para saber si está buena. Con solo una muestra representativa puedes inferir el sabor. En bases de datos gigantes (100M+ filas), TABLESAMPLE te da una muestra aleatoria y representativa para exploración, sin escanear toda la tabla.

🎲 Simulador de Muestreo Estadístico

📊 Simulación: tabla de 10,000,000 filas (100M)
💡 Interactúa con los controles
💬 TABLESAMPLE (SQL:2003) permite muestrear filas sin escanear la tabla completa. SYSTEM: muestreo a nivel de página (rápido, menos aleatorio). BERNOULLI: fila por fila (más lento, más preciso). El porcentaje es aproximado. No reemplaza WHERE con RANDOM() para muestreo exacto.
