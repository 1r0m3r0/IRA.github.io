📈 DuckDB y OLAP en SQL

Análisis OLAP embebido con DuckDB. Columnar storage, consultas analíticas y联接 con PostgreSQL vía postgres_scanner.

🎯 Piénsalo así: DuckDB es como una calculadora científica para tus datos. Mientras PostgreSQL es como una libreta de direcciones (optimizada para muchas transacciones pequeñas), DuckDB está diseñado para análisis pesados: procesar millones de filas con agregaciones complejas. Es embebido (no necesita servidor) y se integra con PostgreSQL vía postgres_scanner para análisis sin mover datos.
