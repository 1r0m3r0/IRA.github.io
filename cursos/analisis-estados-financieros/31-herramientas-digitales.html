Panel 1: Excel de Analista — el Kit Mínimo

🧰 5 funciones que pagan el sueldo

  • BUSCARX: trae cualquier ratio o cuenta por su código desde otra hoja. =BUSCARX("1101", Códigos, Saldos) — reemplaza al viejo BUSCARV y no se rompe si insertas columnas.
  • SI + Y/O + SI.ERROR: semáforos automáticos. =SI([Ebitda]/[Intereses]<2,"🔴",SI(...<4,"🟡","🟢")) envuelto en SI.ERROR para no mostrar #¡DIV/0!
  • Tabla dinámica: resume el mayor (ventas por cliente, gastos por cuenta) en 3 clics. Es tu análisis vertical instantáneo.
  • Formato condicional: pinta de rojo las variaciones >10% (tu regla del Módulo 8) automáticamente.
  • Validación de datos: listas desplegables para escenarios (Base/Optimista/Pesimista) que alimentan todo el modelo sin reescribir fórmulas.

Panel 2: VAN, TIR y Sensibilidad

VAN = −Inversión + Σ Flujot / (1 + r)t  ·  TIR = r que hace VAN = 0

🧮 En Excel (y en la calculadora de abajo)

VAN: =VNA(10%; 400; 400; 400) - 1000 → −Bs 5 TIR: =TIR({-1000; 400; 400; 400}) → ≈ 9.7%

Lectura: VAN ≈ 0 y TIR (9.7%) menor al WACC (digamos 12%) → el proyecto no crea valor: se rechaza aunque "recupere" la inversión nominal. Esa es la diferencia entre mirar caja nominal y mirar valor.

Sensibilidad con Tabla de datos: Datos → Análisis Y si → Tabla de datos. Pon la tasa (8%, 10%, 12%, 15%) en una columna y Excel recalcula el VAN para cada una: en segundos ves a qué tasa el proyecto se vuelve inviable. Es el mismo análisis de escenarios del Módulo 23, pero automatizado.

Panel 3: Power Query — Datos que se Limpian Solos

El 80% del tiempo del analista se va en limpiar datos (EEFF del SIAT en formatos raros, CSVs del banco, reportes con filas basura). Power Query (Datos → Obtener datos) graba la limpieza una vez y la repite con un clic cada mes:

🔄 Receta típica para EEFF bolivianos

  1. Importar: desde Excel/CSV del Formulario 605 o del sistema contable.
  2. Limpiar: quitar filas vacías, separar código y nombre de cuenta, cambiar tipo a número (ojo con el formato Bs 1.234,56).
  3. Combinar: anexar los 12 meses o 5 años en una sola tabla con columna "Período".
  4. Cargar: al modelo de datos → alimenta tus tablas dinámicas, tus ratios y (Módulo 32) tu Power BI.
Fuentes digitales gratuitas en Bolivia: BBV (EEFF de emisores), ASFI (estadísticas del sistema financiero), SIN/SIAT (tus propios EEFF del Form. 605), INE (inflación y tipo de cambio para ajustar series).

Panel 4: Protocolo Anti-Errores del Modelo

✅ Las 5 reglas de oro

  1. Supuestos separados: una hoja "SUPUESTOS" (en azul) con tasa, crecimiento, IUE. Nunca números quemados dentro de fórmulas.
  2. Una fórmula, muchas celdas: la misma lógica copiada en toda la fila. Si cada año tiene fórmula distinta, el error es invisible.
  3. Chequeos de cuadre: Activo = Pasivo + Patrimonio en cada período; la suma de orígenes = aplicaciones (Módulo 25). Si no cuadra, pinta rojo.
  4. Versionado: nombre_con_fecha_v03.xlsx + una línea de "qué cambió". Nunca "final_final2.xlsx".
  5. Documenta lo raro: un comentario en cada ajuste no obvio (diferencia de cambio, partida extraordinaria). Tu "yo" de dentro de 6 meses te lo agradecerá.
