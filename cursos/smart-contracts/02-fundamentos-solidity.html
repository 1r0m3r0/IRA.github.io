🛠️ FUNDAMENTOS DE SOLIDITY 🛠️

Domina el lenguaje de los smart contracts. Escribe, compila y ejecuta tu primer código en la EVM.

🧃 Piénsalo así: Un smart contract es como una máquina expendedora. Tú metes monedas (ETH + datos), presionas un botón (llamas a una función), y la máquina sigue reglas fijas e inmutables para darte un producto (resultado). No hay dependiente, no hay discusión — el código es la ley. La EVM es el pasillo donde están todas las máquinas. Solidity es el idioma en el que escribes las instrucciones para cada máquina.

⚙️ EVM

Ethereum Virtual Machine — computadora global descentralizada. Ejecuta bytecode de Solidity en cada nodo. Turing-completa pero con costo por operación (gas).

⛽ Gas

Combustible de la EVM. Cada instrucción (ADD, SSTORE, BALANCE) cuesta gas. Más complejidad = más gas. El precio lo paga quien envía la transacción.

💾 Storage / Memory

Storage = disco duro (persistente, caro). Memory = RAM (temporal, barato). Calldata = entrada de solo lectura. Elegir bien ahorra gas.

📋 ABI

Application Binary Interface — el "contrato" que describe funciones y parámetros en JSON. Wallets y dApps lo usan para saber cómo llamar al contrato.
