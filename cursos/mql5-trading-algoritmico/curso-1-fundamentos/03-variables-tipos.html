int · double · string Operadores Code Blocks

💡 Piénsalo así: Las variables son como cajas etiquetadas donde guardas cosas. int es una caja para números enteros, double para decimales, string para texto. Los operadores son las herramientas que usas para combinar esas cajas.
Tipos de Datos en MQL5
int
Entero 32 bits (-2.1B a 2.1B)
double
Decimal de 64 bits
string
Cadena de texto
bool
true / false
color
Color RGB para gráficos
datetime
Fecha y hora (segundos)
uint8
Entero sin signo 8 bits
int8
Entero con signo 8 bits
