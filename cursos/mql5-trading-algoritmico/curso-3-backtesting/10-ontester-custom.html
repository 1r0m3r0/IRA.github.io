🏆 Piénsalo así: El Profit Factor es como juzgar un atleta solo por su velocidad. Pero un buen atleta necesita velocidad + resistencia + técnica + salud mental. OnTester te permite crear tu propio "juez" que mira múltiples métricas a la vez. Así encuentras estrategias que son buenas en todo, no solo en una cosa.

Código MQL5 — OnTester

//+------------------------------------------------------------------+
//| Custom Optimization Criterion |
//+------------------------------------------------------------------+
double OnTester()
{
  // Get standard metrics
  double pf = TesterStatistics(STAT_PROFIT_FACTOR);
  double sharpe = TesterStatistics(STAT_SHARPE_RATIO);
  double dd = TesterStatistics(STAT_EQUITY_DD);
  double recovery = TesterStatistics(STAT_RECOVERY_FACTOR);
  double trades = TesterStatistics(STAT_TRADES);

  // Custom weighted score
  double score = pf * W_PF + sharpe * W_SHARPE
                + (1 - dd/100) * W_DD
                + recovery * W_RECOVERY;

  return score;
}
