Conceptos Fundamentales

📈 Proceso AR(1)

Modelo autorregresivo de orden 1: el error actual depende del error anterior.

εₜ = ρεₜ₋₁ + νₜ

📐 Durbin-Watson

Estadístico para detectar autocorrelación de orden 1. d ≈ 2(1-ρ̂).

d = Σ(êₜ-êₜ₋₁)²/Σêₜ²

⚠️ Consecuencias

Errores estándar sesgados, R² inflado, inferencia no válida. β̂ sigue siendo insesgado.

se(β̂) → subestimado (ρ > 0)

🛠️ Soluciones

Cochrane-Orcutt (transformación AR(1)), Newey-West (errores HAC), diferenciación.

Yₜ-ρYₜ₋₁ = β₀(1-ρ) + β₁(Xₜ-ρXₜ₋₁) + νₜ
