Conceptos Fundamentales

📦 lm()

Función principal para estimar modelos lineales en R. Sintaxis: lm(Y ~ X, data = df).

modelo <- lm(Y ~ X1 + X2, data = datos)

📊 summary()

Proporciona coeficientes, errores estándar, t-valor, p-valor, R², R² ajustado y F-test.

summary(modelo)

📈 plot()

Gráficos de diagnóstico: residuos vs ajustados, Q-Q normal, scale-location, residuos vs leverage.

plot(modelo)

🛠️ Flujo de trabajo

Cargar datos → explorar → estimar → diagnosticar → interpretar → predecir.

read.csv() → lm() → summary() → plot() → predict()
