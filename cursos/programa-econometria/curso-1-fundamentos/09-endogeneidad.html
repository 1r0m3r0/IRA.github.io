💡 Piénsalo así: La endogeneidad es como un termómetro que se calienta al sol: no sabes si mide la temperatura del aire o la suya propia. Una variable instrumental es como ponerlo a la sombra.
Conceptos Fundamentales

⚠️ Endogeneidad

Ocurre cuando una variable explicativa está correlacionada con el error del modelo. Causas: omisión, simultaneidad, error de medición.

corr(X, ε) ≠ 0

🎯 Variable Instrumental (Z)

Una variable Z es un instrumento válido si: (1) relevancia: corr(Z,X)≠0, (2) exogeneidad: corr(Z,ε)=0.

Z → X → Y

📐 MC2E

Mínimos Cuadrados en Dos Etapas: 1ra etapa: X = Zγ + ν. 2da etapa: Y = X̂β + ε.

X̂ = Z(Z'Z)⁻¹Z'X

🔍 Pruebas

Test de Hausman (endogeneidad), test de sobreidentificación (Sargan/Hansen), estadístico F en primera etapa.

F > 10 → instrumento fuerte
