🔮 Nowcasting Macroeconómico

Predicción del PIB en tiempo real con datos de distintas frecuencias

Tiempo Real MIDAS Bridge
Módulo 11 de 12
💡 Piénsalo así: Nowcasting es como armar un rompecabezas mientras siguen llegando piezas nuevas. El PIB se publica trimestralmente con retraso, pero tienes datos mensuales (IPI, empleo, ventas) que llegan cada semana. Nowcasting actualiza tu estimación del PIB cada vez que llega un nuevo dato, como un GPS que se refina con cada nueva señal.
Métodos de Nowcasting

🔗 Bridge Equations

yₘ^Q = α + βxₘ^M + εₘ. Usa datos mensuales para predecir PIB trimestral. Simple y transparente.

PIBₘ = α + β·IPIₘ + εₘ

📊 MIDAS

Mixed Data Sampling. yₘ = β₀ + β₁B(L^(1/m);θ)xₘ^(m) + εₘ. Polinomio de rezagos para datos de alta frecuencia.

MIDAS: yₘ = βB(L; θ)xₘ^(m)

🧩 Factor Nowcasting

Factores de gran base mensual + ecuación puente. Maneja el ragged edge (fechas de publicación dispares).

fₘ = PCA(Xₘ) → PIBₘ = α + γfₘ

🔄 BVAR Nowcasting

BVAR mensual con priors de Minnesota. Predice el PIB dentro del VAR y agrega datos a medida que llegan. Actualización secuencial.

BVAR(M) → PIBₘ trimestral
