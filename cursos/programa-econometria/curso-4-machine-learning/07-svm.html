Márgenes, kernel trick y clasificación no lineal para econometría

Maximal Margin Kernel Trick C parameter
Módulo 7 de 12
💡 Piénsalo así: SVM es como un urbanista que traza la carretera más ancha posible entre dos barrios (clases). El kernel trick es como poner un espejo que deforma el espacio para que calles curvas se vuelvan rectas en el reflejo. Los support vectors son las casas más cercanas a la carretera, las que definen su trazo.
Teoría: SVM y Kernels

Maximal Margin Classifier

Encuentra el hiperplano que maximiza la distancia (margen) entre las dos clases. Solo los puntos en el borde del margen importan (support vectors).

max M s.t. yi(β0 + β'xi) ≥ M

Support Vector Classifier

Versión con margen suave: permite errores de clasificación controlados por el parámetro C (costo). C grande → menos errores pero margen más estrecho.

C ∑ εi + (1/2)||β||2

Kernel Trick (RBF, Polynomial)

Proyecta los datos a un espacio de mayor dimensión sin calcular explícitamente la transformación. RBF: K(x,x') = exp(-γ||x-x'||2).

K(x, x') = φ(x) · φ(x')

SVM en Econometría

Usado para clasificación con fronteras no lineales: predicción de default, clustering de patrones de consumo, clasificación de textos.

f(x) = sign(Σ αi yi K(x, xi) + b)
