💡 Piénsalo así: Random Forest es como un comité de expertos donde cada uno vota y el promedio es mejor que cualquier experto individual. Boosting es como un estudiante que aprende de sus errores: cada nuevo modelo se enfoca en lo que los anteriores fallaron. XGBoost es la versión turbo de ese estudiante.
Teoría: RF, Boosting, XGBoost

Bagging y Random Forest

Bagging: bootstrap + árbol. RF: bagging + muestreo aleatorio de variables en cada split. Reduce varianza sin aumentar sesgo.

f̂bag(x) = (1/B) Σ f̂b(x)

Gradient Boosting

Construye árboles secuencialmente, cada uno ajusta los residuos del anterior. Minimiza pérdida con gradient descent funcional.

fm(x) = fm-1(x) + η hm(x)

XGBoost

Implementación optimizada de Gradient Boosting con regularización L1/L2, poda de árboles y manejo de missing values. Altamente eficiente.

Obj = Σ L(yi, f(xi)) + Σ Ω(hk)

Variable Importance y PDP

Importancia: reducción total de impureza por variable. Partial Dependence: efecto marginal de una variable sobre la predicción promediando sobre las demás.

PDP(xj) = (1/n) Σ f(xj, X-j,i)
