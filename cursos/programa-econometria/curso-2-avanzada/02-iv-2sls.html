🎯 Variables Instrumentales / 2SLS

Cuando el regresor y el error se confabulan, el instrumento llega al rescate

IV 2SLS Instrumentos débiles
Módulo 2 de 12
💡 Piénsalo así: La endogeneidad es como un GPS que recibe interferencia: la señal se distorsiona. Un instrumento es como una torre de repuesto: no tiene interferencia y te da la posición correcta. 2SLS es el proceso de usar esa torre: primero calculas dónde debería estar (primera etapa), luego usas esa posición limpia para llegar a tu destino (segunda etapa).
¿Por qué IV?

🎯 Endogeneidad

Ocurre cuando un regresor X está correlacionado con el error ε. Causas: variable omitida, simultaneidad, error de medición. MCO es inconsistente.

Cov(X, ε) ≠ 0

🔧 Instrumento Z

Variable que cumple: (1) Relevancia: Cov(Z,X) ≠ 0, con F>10 en primera etapa. (2) Exogeneidad: Cov(Z,ε) = 0.

Cov(Z,X)≠0, Cov(Z,ε)=0

📐 2SLS - Primera Etapa

Regresionar X sobre Z: X̂ = Z(Z'Z)&supmin;¹Z'X. Obtener el valor predicho de X libre de la correlación con ε.

X̂ = Z(Z'Z)&supmin;¹Z'X

📐 2SLS - Segunda Etapa

Regresionar Y sobre X̂: β̂_2SLS = (X̂'X̂)&supmin;¹X̂'Y. El estimador es consistente aunque no insesgado.

Y = X̂β + ε
