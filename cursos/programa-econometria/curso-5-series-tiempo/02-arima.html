📊 ARIMA y Box-Jenkins

Modelos autorregresivos, medias móviles y la metodología sistemática de Box-Jenkins

AR(p) MA(q) ARIMA(p,d,q) ACF/PACF
Módulo 2 de 12
💡 Piénsalo así: ARIMA es como un chef que predice el siguiente ingrediente: los modelos AR usan ingredientes anteriores (pasado), MA corrige errores previos (como ajustar la sal), y la diferenciación elimina tendencias (como nivelar una mesa coja). Box-Jenkins es la receta paso a paso para encontrar el mejor modelo.
Modelos ARIMA

📈 AR(p) — Autorregresivo

yₜ = φ₁yₜ₋₁ + ... + φₚyₜ₋ₚ + εₜ. El valor actual depende linealmente de p valores pasados más un error.

yₜ = φ₁yₜ₋₁ + ... + φₚyₜ₋ₚ + εₜ

🌊 MA(q) — Media Móvil

yₜ = εₜ + θ₁εₜ₋₁ + ... + θₙεₜ₋q. Combina errores pasados para predecir el presente.

yₜ = εₜ + θ₁εₜ₋₁ + ... + θₙεₜ₋q

🔧 ARIMA(p,d,q)

Integra AR + MA + diferenciación. d = orden de diferenciación para lograr estacionariedad.

(1-B)ᵈyₜ = ARMA(p,q)

📊 ACF y PACF

ACF: correlación entre yₜ e yₜ₋ₖ. PACF: correlación parcial eliminando efectos intermedios. Clave para identificar p y q.

ACF(k) = Corr(yₜ, yₜ₋ₖ)
Metodología Box-Jenkins

1. Identificación

Usar ACF/PACF para identificar p, d, q tentativos. Examinar estacionariedad.

2. Estimación

Estimar parámetros por máxima verosimilitud o mínimos cuadrados condicionales.

3. Validación

Verificar residuos tipo ruido blanco. Tests de Ljung-Box, normalidad, heterocedasticidad.

4. Pronóstico

Generar predicciones puntuales e intervalos de confianza.

Simulación: Modelos ARMA
