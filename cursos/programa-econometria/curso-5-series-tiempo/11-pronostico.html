Evaluación de Pronósticos

📐 RMSE, MAE, MAPE

RMSE = √(mean squared error). MAE = mean absolute error. MAPE = mean absolute percentage error.

RMSE = √(Σ(yₜ-ŷₜ)²/T)

📊 Diebold-Mariano Test

Compara la precisión de dos métodos de pronóstico. H₀: igual precisión. Estadístico DM ~ N(0,1).

DM = d̄ / √(Var(d)/T)

📦 MCS (Model Confidence Set)

Conjunto de modelos que contiene al mejor con nivel de confianza (1-α). Eliminación secuencial basada en tests de igualdad.

🔮 Forecast Combination

Combinar múltiples modelos mejora el pronóstico. Promedio simple, ponderado por varianza, o por desempeño reciente (AIC weights).

ŷₜ = Σwᵢŷᵢₜ
Direct vs Iterated Multi-step

➡️ Direct Multi-step

Estimar modelo específico para cada horizonte h: yₜ₊ₕ = f(yₜ, xₜ) + εₜ₊ₕ. Robusto a errores de especificación pero menos eficiente.

🔄 Iterated Multi-step

Estimar modelo 1-paso, iterar para h-pasos. Más eficiente si el modelo es correcto, pero propaga errores.
