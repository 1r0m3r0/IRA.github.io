💡 Piénsalo así: SVAR es como un detective que observa correlaciones (VAR) y luego impone restricciones para identificar causalidad. Cholesky es como ordenar a los sospechosos: el primero afecta a todos, el último solo se afecta a sí mismo. Cambiar el orden cambia la historia.
Identificación Estructural

📐 SVAR General

A₀yₜ = c + A₁yₜ₋₁ + ... + Aₚyₜ₋ₚ + εₜ. A₀ captura relaciones contemporáneas. Necesita restricciones para identificación.

A₀yₜ = c + A₁yₜ₋₁ + ... + εₜ

🔷 Cholesky (Sims 1980)

Descomposición recursiva: A₀ es triangular inferior. El orden de las variables importa y cambia las IRF.

📏 Blanchard-Quah (1989)

Restricciones de largo plazo: shocks de demanda no afectan el producto en el largo plazo. La matriz de IRF acumulada tiene ceros.

✏️ Sign Restrictions (Uhlig 2005)

No ceros exactos, sino signos: un shock monetario aumenta la tasa, disminuye la inflación. Más flexible.
