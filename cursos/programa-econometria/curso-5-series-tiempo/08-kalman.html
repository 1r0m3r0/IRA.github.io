🎛️ State Space y Kalman Filter

Filtrado, suavizado y parámetros variables en el tiempo

Estado-Espacio Kalman Predicción Suavizado
Módulo 8 de 12
💡 Piénsalo así: Kalman filter es como navegar con GPS en medio de la niebla: el estado real (posición) es invisible, pero tienes mediciones ruidosas (señal GPS). El filtro combina tu modelo de movimiento (predicción) con la medición (actualización) para estimar tu posición exacta. En economía, estimamos el PIB potencial o betas variables de CAPM.
Representación Estado-Espacio

📐 Ecuación de Estado

αₜ = Tαₜ₋₁ + Rηₜ. El estado (no observado) evoluciona como un proceso de Markov de primer orden.

αₜ = Tαₜ₋₁ + Rηₜ

📏 Ecuación de Medición

yₜ = Zαₜ + εₜ. Relaciona el estado con las observaciones.

yₜ = Zαₜ + εₜ

🔄 Kalman Filter

Paso 1: Predicción (estado y varianza forward). Paso 2: Actualización (incorporar nueva observación). Paso 3: Suavizado (retrospectivo para toda la muestra).

📊 Filtered vs Smoothed

Filtered: estimación con información hasta t. Smoothed: estimación con toda la muestra (más precisa).

Aplicaciones

📈 Local Level Model

yₜ = μₜ + εₜ, μₜ = μₜ₋₁ + ηₜ. Random walk + ruido. La señal es el nivel subyacente.

yₜ = μₜ + εₜ, μₜ = μₜ₋₁ + ηₜ

📉 CAPM con Beta Variable

rᵢₜ = α + βₜ·rₘₜ + εₜ. βₜ = βₜ₋₁ + ηₜ. El riesgo sistemático cambia en el tiempo.
