Caracteristicas Principales

Motor de Simulacion Completo

Simula estrategias de trading sobre datos historicos con reglas configurables de entrada y salida. Soporta SMA cross, RSI, momentum, take profit y stop loss.

Metricas Profesionales

Calcula retorno total, Sharpe Ratio (anualizado), maximo drawdown, win rate, numero de trades, y profit factor. Todo visible en tiempo real.

Equity Curve con Canvas API

Grafico de la curva de equity dibujado nativamente con Canvas API. Visualiza la evolucion del capital durante el periodo de backtest con marcadores de entrada y salida.

Importacion CSV Flexible

Arrastra y suelta archivos CSV con datos de precios. Detecta automaticamente columnas de fecha y precio. Incluye datos de muestra de BTC para pruebas rapidas.

Stack Tecnologico

Frontend

  • Canvas API (Charting)

Calculos

  • SMA / RSI / Momentum
  • Sharpe Ratio anualizado
  • Max Drawdown
  • Win Rate / Profit Factor

Backend (Opcional)

  • Python (pandas, numpy)
  • Flask / FastAPI API
  • yfinance data source
  • PostgreSQL storage
