Caracteristicas Principales

Fear & Greed Index en Tiempo Real

Conexion a la API de Alternative.me para obtener el indice de miedo y codicia del mercado cripto. Indicador visual con aguja animada y clasificacion de sentimiento.

Sentimiento de Redes Sociales

Analisis de sentimiento agregado de Twitter/X, Reddit, medios de noticias y datos on-chain. Barras de progreso con codigos de color por fuente.

Grafico Historico Canvas

Visualizacion de la evolucion del sentimiento versus el precio de Bitcoin en los ultimos 30 dias. Correlacion visual entre sentimiento y accion del precio.

Stack Tecnologico

Frontend

  • JavaScript ES6+
  • Canvas API (Gauges & Charts)
  • CSS Animations

Fuentes de Datos

  • Alternative.me API (F&G)
  • CoinGecko API (Prices)
  • Social Media APIs

Backend (Opcional)

  • Python (NLP models)
  • HuggingFace Transformers
  • Twitter/Reddit scrapers
